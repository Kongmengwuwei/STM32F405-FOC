# 从零读懂这个 FOC 工程

这份教程按**当前默认固件**讲：STM32F405、M0 功率接口、TLE5012B 编码器、ZH3620-1 电机、塑料臂负载。M0 是板上的三相输出位置，不是电机名字；同一套应用代码也可编译 M1/MT6835 等组合。配置与实测边界见[项目入口](../../../README.md)，每个文件的职责见[文件导览](文件导览.md)。

## 1. 先认识这条闭环

直流电源提供母线电压，三相逆变桥通过六路 PWM 让 A/B/C 绕组产生旋转磁场。磁编码器报告转子**机械角度**；分流电阻与 ADC 报告 B/C 相电流，A 相由 `Ia = −Ib − Ic` 求出。控制器必须让电流方向随转子位置转动，才可以稳定地产生期望转矩。

```text
上位机 Iq / rpm / pos
       ↓
位置目标 → 速度目标 → 速度 PI（1 kHz）→ Iq 目标
       ↓                           ↓
       └──────────────→ 电流 PI（M0 10 kHz）← 编码器角度 + B/C 电流
                                  ↓ Ud/Uq
                         逆变换 → SVPWM → 三相 PWM
                                  ↓
                           电机转动、再次采样
```

电流是最内层，因为电磁转矩要先由电流建立；速度和位置较慢，由外层按需请求电流。`Iq` 是垂直于转子磁场的电流，主要形成转矩；`Id` 沿转子磁场，本工程目标为 0 A。**电源面板电流、单相电流和 Iq 不是同一数值。**

## 2. 一次采样周期里发生什么

M0 的 TIM1 在中心对齐 PWM 的固定相位触发 ADC1，顺序读取 PC0/PC1 的 B/C 相电流；PA6 测母线，SPI3 读取 TLE5012B 角度。有效数据进入 `app_sample()`，再进入 `foc_step()`。当前每 100 µs 计算一次电流环；M1 使用 TIM8 与另一条双 ADC DMA 链路，每 50 µs 一次。两者最终调用同一套 `foc.c` 数学和 `control.c` 外环。

默认 M0 选 28 周期 ADC 采样、TIM1 触发计数 8200。它要落在 B/C 低侧导通、开关噪声已建立的窗口里。采样太早或太晚都可能使读数受边沿影响，甚至失去低侧可测窗口。曾比较五个触发点和同步双 ADC；小电流重复数据没有证明改点或双 ADC 稳定更好，所以保持顺序采样。具体证据见[电流采样与调参](../../../docs/current-sampling-noise.md)。

## 3. 机械角度如何变成电角度

ZH3620-1 是 14 磁极，即 **7 极对**。转子机械转一圈，电角度转七圈。可以把基本关系记作 `电角度 = 7 × 机械角度 + 安装偏置`，再按 360° 取模。安装偏置取决于磁钢、编码器零位和三相接线；第一次使用或改变接线后，要让轴可自由转动并发送 `cal`。校准成功才把电角度关系保存到 Flash。上电只估计静止电流零偏，不自动转动校准。

传感器帧无效时无法可靠换相，功率输出会关闭。不同编码器不是只改分辨率：TLE5012B 和 MT6835 的 SPI 模式、帧校验和读数路径不同，分别在 `Hardware/encoder/` 适配；上层只接收统一的机械角度。

## 4. 电流怎样算，PWM 怎样生成

先由 `Ia = −Ib − Ic` 补齐三相，再做 Clarke 变换，把三相投影到静止的 α/β 轴。Park 变换用电角度把静止电流转到随转子旋转的 d/q 轴。q 轴实测值与 `Iq_ref` 相减就是转矩电流误差；d 轴目标为 0。两套 PI 分别把误差转为 `Ud/Uq` 电压，当前 ZH3620-1 的电流 PI 是 `Kp=0.20 V/A`、`Ki=192 V/(A·s)`，M0 在 10 kHz 下逐次积分。

逆 Park 把 `Ud/Uq` 变回静止坐标；`foc_modulate()` 用 SVPWM 计算三相 PWM 占空比，并尽量留足低侧电流采样窗口。若母线电压或采样窗口使期望电压无法完整输出，程序缩小电压矢量并回算积分器，避免积累一个硬件做不到的指令。输出写入定时器预装载寄存器，到下个 PWM 边界才生效。VOFA 的 `Ud/Uq` 是软件计算的输出，不能代替示波器测到的真实栅极和相电压。

小电流测试发现旧 `Ki=24` 的回零拖尾偏长；带载对照后保留 `Ki=192`，原始电流噪声并没有因此被“消除”。电流采样绝对比例尚未独立仪器标定，不能把板上显示的安培值直接当作已确认的绝对电流。

## 5. 三种命令分别控制什么

| 命令 | 上层怎样变成 Iq 目标 |
|---|---|
| `Iq 0.10` | 直接设 q 轴电流目标；电流模式 |
| `rpm 30` | 速度 PI 每 1 ms 比较目标与实际转速，计算 Iq 目标 |
| `pos 15` | 位置 P 根据距离计算速度目标，考虑最高接近速度和刹车距离；速度 PI 再产生 Iq 目标 |

带臂默认速度 PI `Kp=0.18`、`Ki=0.48`，速度目标变化率 4500 rpm/s；位置 P 为 `12 rpm/°`，位置加速/刹车 4000/3200 rpm/s，接近速度上限 150 rpm。裸轴的惯量和稳定性不同，需选 `FOC_LOAD_PROFILE=FREE_SHAFT`；不能把 M0/M1 当负载档案。带臂的定位到位、超调和电流代价见[最新实测](../../../docs/position-speedup-and-foc-roadmap-2026-09-28.md)。

命令通过原生 USB CDC 或 USART2 收到，必须以实际换行结束。默认 `WARN` 下单次目标持续有效；即使拔掉 USB 也不会自动停机。`stop` 关闭输出；`Iq 0` 只是零转矩目标，`rpm 0` 和 `pos 0` 仍在闭环。`clear` 清告警，不关闭输出。语法、VOFA 连接和通道表见[VOFA 指南](../../../docs/vofa-quickstart.md)。

## 6. 状态、告警和如何学习代码

上电静止测零偏后处于待机；`cal` 扫描、保存安装零点；目标命令经短暂预充进入运行。普通电流/转速/母线诊断阈值在 WARN 下只记录告警，不裁剪有限目标。编码器角度无效、ADC 不可用等导致控制无法计算时仍关闭输出。这一策略适合当前实验台的短测，持续运行能力需另外测电流、温升和硬件波形。

建议沿 `Core/Src/main.c → App/Control/app.c:app_sample → App/FOC/foc.c:foc_step → App/Hardware/bsp/bsp_motor.c` 读内环；再沿 `Control/app.c` 的命令解析到 `Control/control.c` 读速度和位置。每遇到一个变量，先写出**单位、更新频率、谁产生、谁消费**。先在 VOFA 看目标/实际 Iq，再看速度和位置；判断响应时间要用固件时间戳，不能只按 PC 发送按钮的瞬间估计。构建和主机测试见[VS Code 指南](../../../docs/vscode-build.md)与[测试目录](../tests/README.md)。
