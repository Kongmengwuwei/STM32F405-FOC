# 逐文件导览：当前固件从哪里读

先看[初学者教程](FOC-从零读懂这个工程.md)，再按本页对照源码。下面路径均相对于 `variants/m1-mt6835/`。通常 `.h` 声明类型、参数和对外函数，`.c` 实现它们；同名文件在表中合写。文件夹名称 `m1-mt6835` 是历史名称，目前默认组合为 M0/TLE5012B/ZH3620-1。

## 应用与配置

| 文件 | 作用 |
|---|---|
| `App/Control/app.c/.h` | 初始化与主循环入口；解析 USB/UART 命令、接收一次采样、组织遥测、处理校准保存 |
| `App/Control/control.c/.h` | 三种控制模式、速度 PI、位置轨迹、速度估计和 1 kHz 外环 |
| `App/Control/telemetry.h` | 兼容组与总览通道的遥测数据结构 |
| `App/FOC/foc.c/.h` | 电流零偏、传感器角度、电角度校准、Clarke/Park、Id/Iq PI、逆 Park、SVPWM、告警与停机状态 |
| `App/FOC/sine_table.inc` | `foc.c` 使用的正弦表，非独立编译单元 |
| `App/Config/foc_port.h` | M0/M1 定时器、ADC 路径和诊断参数 |
| `App/Config/foc_encoder_profile.h` | TLE5012B/MT6835 选择及传感器参数 |
| `App/Config/foc_motor.h` | ZH3620-1 与参考电机的极对数、电气数据、PI 和不同负载档案 |
| `App/Config/foc_profile.h` | 合成接口、电机、编码器与安装编号，用于配置身份及校准记录 |
| `App/Config/foc_policy.h` | WARN/TRIP 行为选择 |
| `App/Config/foc_telemetry.h` | USB 帧率与默认日志设置 |
| `App/Protocols/JustFloat/justfloat.h` | 数值帧封装与 `+Inf` 帧尾 |

## 板级驱动

| 文件 | 作用 |
|---|---|
| `App/Hardware/bsp/bsp_adc_m0.c` 与 `bsp_adc.c/.h` | M0 顺序/可选双 ADC 采 B/C 电流，M1 双 ADC DMA 路径；母线采样及数据有效性 |
| `App/Hardware/bsp/bsp_motor.c/.h` | M0/M1 三相 PWM 提交、关断、采样时序、Flash 校准读写 |
| `App/Hardware/bsp/bsp_motor_record.h` | Flash 校准记录 v3 的格式、身份和校验 |
| `App/Hardware/encoder/bsp_encoder.h`、`bsp_encoder_tle5012b.c`、`bsp_encoder_mt6835.c` | 将不同磁编码器包装成统一角度输入 |
| `App/Hardware/tle5012b/tle5012b_protocol.c/.h` | TLE5012B SPI 帧、状态和角度解码 |
| `App/Hardware/mt6835/mt6835.c/.h`、`mt6835_port_stm32.c/.h` | MT6835 帧 CRC/角度解码与 STM32 SPI/DMA 适配 |
| `App/Hardware/bsp/bsp_usb.c/.h` | 原生 USB CDC 发送队列、DTR 会话、接收背压 |
| `App/Hardware/bsp/bsp_uart.c/.h` | USART2 命令接收、DMA 发送与队列 |
| `App/Hardware/bsp/bsp_can.c/.h` | CAN1 收发与队列；尚无应用层电机命令协议 |

## 芯片入口与构建

| 文件/目录 | 作用 |
|---|---|
| `Core/Src/main.c` | CubeMX 入口，初始化外设并启动 `app_init()` |
| `Core/Src/stm32f4xx_it.c` | 中断入口，把 ADC、SPI、定时器和通信事件送给驱动/应用 |
| `Core/Src/adc.c`、`tim.c`、`spi.c`、`dma.c`、`usart.c`、`can.c`、`gpio.c` | CubeMX 外设初始化；BSP 启动后会覆写部分运行时寄存器设置 |
| `Core/Src/stm32f4xx_hal_msp.c`、`system_stm32f4xx.c` | 外设底层初始化与系统时钟支持 |
| `Core/Inc/` | 上述入口和外设的声明与 STM32 HAL 配置 |
| `USB_DEVICE/App/`、`USB_DEVICE/Target/`、`Middlewares/ST/STM32_USB_Device_Library/` | CDC 描述符、回调以及 ST USB 设备协议栈 |
| `Drivers/STM32F4xx_HAL_Driver/`、`Drivers/CMSIS/` | ST HAL 与 ARM/STM32 头文件；初学者无需逐个读完整厂商库 |
| `CMakeLists.txt`、`cmake/`、`STM32F405XX_FLASH.ld`、`startup_stm32f405xx.s` | 选择源码、交叉编译、存储布局和上电入口 |
| `STM32F405-FOC.ioc` | CubeMX 基础外设配置；手写条件编译和 BSP 覆盖不能靠单次重新生成还原 |

现行主机回归测试在 [`tests/`](../tests/README.md)，PC 采集与分析工具在 [`tools/bench/`](../tools/bench/README.md)。板卡引脚见[硬件映射](../../../docs/hardware-map.md)；默认通道和命令见[VOFA 指南](../../../docs/vofa-quickstart.md)。
