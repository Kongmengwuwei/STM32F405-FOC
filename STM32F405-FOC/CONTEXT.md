# 有感 FOC 术语

本项目以转子位置传感器提供的角度为反馈，逐步构建三相永磁电机的磁场定向控制。

## Language

**相电流**：流经电机 A、B、C 三相绕组端子的电流，正方向以流入电机为准。

**电角度**：定子 A 相轴与转子磁链方向之间的角度；机械角度每转一圈，电角度转过的圈数等于极对数。
_Avoid_: 编码器角度

**d 轴电流**：沿转子磁链方向的电流分量。

**q 轴电流**：垂直于转子磁链方向的电流分量，正方向须与相序和电角度约定一致。

**有感 FOC**：使用位置传感器测得的转子角度进行磁场定向控制。
_Avoid_: 开环 FOC

**驱动就绪**：母线、相电流校准、角度和输出安全条件均已确认，但尚未向功率级输出 PWM 的状态。

**故障锁存**：发生传感、采样、母线或时序故障后，驱动保持禁止输出，直到故障原因排除并经过明确确认。

**功率接口**：驱动板上的一组三相功率输出与相电流采样连接。M0 和 M1 是功率接口名称，不是电机型号。
_Avoid_: M0 电机、M1 电机

**电机型号**：电机本体的型号，用于确定极对数、额定范围和控制参数；本项目已知的型号为 ZH3620-1。原参考项目电机的准确型号待确认。

**编码器型号**：提供转子机械角度的传感器型号，如 TLE5012B 或 MT6835；它与功率接口、电机型号分别选择。

**安装实例**：一台电机与磁铁、编码器和三相接线的具体装配；重新安装后可能需要新的电角度零点，即使电机和编码器型号未变。
