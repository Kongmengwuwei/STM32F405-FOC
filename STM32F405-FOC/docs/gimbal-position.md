# 双轴云台位置控制

当前顶层默认构建 `FOC_DUAL=ON`、`FOC_GIMBAL=ON`。M0 是下侧水平轴，M1 是上侧竖直轴；编码器接线仍为 M0 → SPI1/PA1、M1 → SPI3/PA0。本阶段实现两轴独立的位置保持，不含 IMU 姿态稳定、轴间重力补偿或自动回中。

| 参数 | M0 水平轴 | M1 竖直轴 |
|---|---|---|
| 正常位置目标，相对上电起点 | 连续多圈（数值目标保护 ±1,000,000°） | −85°～+85° |
| 实际位置停机边界，相对上电起点 | 无角度停机边界 | −90°～+90° |
| 最大轨迹速度 | 4 RPM，即 24°/s | 5 RPM，即 30°/s |
| 轨迹加速、减速 | 10 RPM/s，即 60°/s² | 同 M0 |
| 外环 Iq 限幅 | ±0.60 A | ±2.00 A（短测候选） |
| 相电流停机阈值 | 1.50 A | 3.00 A |
| 校准电流 / 电压上限 | 0.60 A / 0.60 V | 0.60 A / 0.30 V |

M1 目标在两侧各留 5° 余量；用户已确认 M0 接线允许连续多圈，取消该轴的角度限位。限位依据连续机械位移，经过编码器 0°/360° 时仍连续计算，不会选取跨圈的最短路径。参数在 `variants/m1-mt6835/App/Config/foc_gimbal.h`；两轴各自的目标、积分、限位计数和故障独立。

## 上电与操作

1. 断电时将结构摆到水平、竖直的中间位置，确认接线自然松弛。**每次 MCU 复位或重新上电，第一笔有效编码器位置建立新的行程中心**；固件无法识别断电期间已绕了几圈，不能反复复位来扩大行程。
2. 上电两轴保持关闭，先完成静止电流零偏估计。本轮实测母线约 12 V。位置控制必须有各轴安装对应的有效电角度校准；无有效记录时命令会被拒绝。
3. 确需校准时先 `stop`，分别发送 `m0 cal`、`m1 cal`，等待一轴结束再操作另一轴。校准中不能手转轴。校准及 `test` 同样受实际位置停机边界、电流和母线保护约束；校准需扫一电角周，当前 7 极对约对应 51.4° 机械角，初始对齐还可能产生位移，因此装好 L 形负载后的 M1 校准可能触及边界而失败。不要用扩大限位来强行通过校准。改变三相接线或磁铁安装后，应更改对应安装编号并重新校准。
4. 校准成功、结构静止后，可以用下面的小角度命令分别验证，再同时保持两轴。

```text
m0 pos 10
m1 pos 10
gimbal pos 10 -10
m0 pos 0
m1 pos 0
stop
```

`pos` 单位为机械角度。正负号沿编码器机械方向，需用小角度动作确认实际左右、上下方向。连续下发两轴目标后，两轴各自保持位置；`m0 hold`、`m1 hold` 保持当前位置，`m0 stop`、`m1 stop` 关闭对应轴，`stop` 或 `all stop` 关闭两轴。上电和故障清除后均不自动启动或回中。

`m0 zero`、`m1 zero` 只在停机且低于 5 RPM 时允许，将当前显示/命令位置定义为 0°；**不会改变上电行程中心或扩大物理范围**。例如 M1 已从上电中心转到 +40° 再 `zero`，其新命令范围为 −125°～+45°。越界命令被拒绝，原目标保持；可用 USB 的目标通道确认是否接受。`hold` 若当前位置已经超出正常目标范围，也会被拒绝。

云台模式拒绝持续 `rpm`、`Iq` 及底层直接电流命令。调试提供一次性指令：`m0/m1 itest ±0.30` 最多 400 ms（电流单位 A），`stest ±2.00` 最多 1500 ms（单位 RPM），两种测试相对开始位置移动达到 10° 也会停机，不能用重发延长测试。`field 0/90/180/270` 使用 0.20 A 固定定子方向电流，50 ms 上升、250 ms 后自行关闭，不要求电角校准，也不保存记录。短时诊断要求另一轴静止关闭，并保留所有行程/电流/供电保护。位置目标持续有效，不需要 200 ms 刷新，断开 USB 仍保持；退出保持须发送 `stop` 或切断功率。竖直轴停机后失去支撑力，可能受重力下落。

`gimbal pos <M0角度> <M1角度>` 同时设定两轴，任一轴不能接受时整条命令被拒绝。两轴目标于同一采样边界提交；`stop` 或单轴 `stop` 会取消待提交的双轴目标。专用角度输入界面、24 通道对应表与连接配置见[双轴命令与 VOFA 界面](vofa-gimbal.md)。

## 故障与数据

云台模式即使构建选择 `WARN`，仍强制执行位置、相电流、转速、母线和有效采样保护。正常运行时超过 10 RPM 会停机；M0 校准速度保护为 60 RPM，M1 校准为 30 RPM；M1 固定方向 field 诊断仍为 10 RPM。电流 PI 电压矢量上限为母线的 10%。发生故障后锁定停机，不自动恢复。先 `stop` 两轴，排除原因再 `clear`；该操作保留校准与上电行程中心，并重新估计静止电流零偏。若还在实际位置边界外，会再次停机。编码器发生无法判定行程的角度跳变后，`clear` 也不能重新启用该轴，须先断电确认结构和接线回到中间，再复位。

校准调节定子 d 电流、保持 q 电压为零以提供反电势阻尼；field 诊断仍调节两个电流分量。存在有效旧记录时，选择靠近当前转子的起始磁场，减少初始跳动；新零点由实测方向和稳定后的编码器角度求得，并减去起始磁场偏移。正向扫动后等待 1 秒再检查位移，返回后也等待 1 秒再采样。正常校准约 11.75 秒，保存 Flash 时两轴已关闭，遥测可能暂停约 1 秒，采集工具等待到 15 秒完成；不应将保存暂停误判为运动失控。

软件限位检测到越界后关闭驱动，不能阻止断电时的手动旋转、惯性或竖直负载下落；5° 余量是否足够需要当前结构的实测确认。

USB 仍为 24 个 JustFloat 通道、1 kHz。零起算 M0 的 I2/I3 为目标/实际位置，M1 的 I14/I15 为目标/实际位置；I10/I22 为故障码，`12` 为位置越界，`1` 为编码器异常。`hello` 通过 USART2 显示 `gimbal=1`。

## 构建与验证状态

项目根目录 `cmake --preset Debug-local -DFOC_GIMBAL=ON`，随后 `cmake --build --preset Debug-local`。VS Code 默认构建任务也启用云台模式。恢复旧台架双路模式时显式配置 `-DFOC_GIMBAL=OFF`；单路配置同时设 `-DFOC_DUAL=OFF -DFOC_GIMBAL=OFF`。

2026-09-30：ARM GCC 固件构建通过；真实双路命令解析、FOC 和位置外环的主机测试分别在 WARN/TRIP 下通过，共 30 项。测试覆盖双轴正反向定位、靠近目标边界、速度和电流限幅、越界/非数值输入拒绝、两轴独立停止、清零与故障清除后限位保持、负载释放后位置制动优先、校准/试转的正负限位与超速停机、编码器跳变锁定、母线/电流保护及校准阻尼、端点稳定和磁场偏移补偿。主机运动模型结果不代表实机精度或当前 L 形负载稳定性。

2026-10-01：已恢复正常双轴位置控制固件，M0/SPI1 采用 2.625 MHz、M1/SPI3 保持 5.25 MHz。双路静止长读各 10000/10000 CRC 与有效角度通过。新 M0 已建立有效校准：零点 1.652138233 rad、方向 +1；M1 原安装关系经用户确认恢复，保留零点 4.040125847 rad、方向 −1。具体记录见[本日控制测试](gimbal-tuning-2026-10-01.md)和[编码器诊断](encoder-diagnosis-2026-10-01.md)。

M0 在另一轴保持零位时的 ±1°、±10°、±30° 往返和回零通过，最大末端误差 0.073°。M1 在另一轴保持零位时的 ±30°、±60°、±85° 往返和回零通过，最大末端误差 0.111°，170° 往返约 8.04 秒进入 ±0.2°。双轴同时移动 ±3° 及回零也通过。已回零并关闭两轴，最终快照显示无故障、编码器错误计数均为零。位置误差均基于编码器反馈，完整曲线和原始记录见本日报告。

## 当前环路参数

两轴电流 PI 均为 Kp=0.20、Ki=192/s。M0 速度 PI 为 0.08/0.60，位置 P 为 1.00，速度滤波 1 ms；M1 速度 PI 为 0.16/0.40，位置 P 为 1.50，速度滤波 8 ms。电流反馈台架记录不能替代外部电流标定；位置误差以板上编码器反馈为准。

数值目标先在前台解析，再于本周期两轴 PWM 写入完成后提交，避免前台关中断影响采样和 PWM 截止时刻。`stop` 立即取消待提交的两轴目标。故障时持续更新可信的行程和速度遥测，方便观察停机后的实际运动。

位置模式加速继续使用斜率约束；减速时距离制动上限优先，避免负载释放后速度给定下降太慢。当前电流上限来自短时验证，未做长时间保持的温升验收。

位置模式按轴轨迹速度削减加速电流：M0 在 4～5 RPM、M1 在 5～6 RPM。M0 超过 5 RPM 还主动提供反向制动，0.20 A/RPM、最多 0.60 A；更强的正常 PI 制动保留。10 RPM 硬停机独立于轨迹速度，外环积分按可用输出反饱和。
