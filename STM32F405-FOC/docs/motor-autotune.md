# 母线电压适配、R/L 辨识与电流环自整定

2026-10-10：当前 M1 / TLE5012B / L4225-6S420-A / 安装 2 配置已构建、烧录并完成 **12 V 空载**辨识、参数应用、Flash 保存与复位加载。固件上电只校准电流零偏并读取有效记录，不会自动注入或转动；更换电机后由命令触发自动流程。

## 使用方案

电流环使用物理单位：反馈和目标为 A，PI 输出为 V。每个电流采样周期用实时 ADC 母线电压换算 SVPWM 占空比，并按实际母线、ADC 安静窗口及运行电压比例限幅。限幅后的实际电压反馈给积分抗饱和。因此换供电电压时不成倍修改 Kp/Ki，而由调制层自动换算，低电压下可用电压和最高转速仍会下降。当前组合的电机/功率口交集为 **11.1–24 V**；35% 运行电压矢量限制随实际母线变化，外环 Iq 上限仍为 ±6 A。

R/L 辨识采用独立状态机，电角度校准必须已有效、轴必须静止且自由。辨识期间复用 CALIBRATE 状态，不改变旧状态字的三位布局，关闭速度/位置外环，使用限幅电压积分器引导电流，避免依赖待辨识电机的旧电流 PI。整个流程约 **3.6 s**：

1. **电阻**：沿已校准 d 轴施加两个正直流电流水平（默认 0.75 / 1.5 A），每级 0.6 s，前 0.2 s 整定、后 0.4 s 求均值。计算 `R = (Ud₂ − Ud₁)/(Id₂ − Id₁)`；相同电流方向下，用差分减小固定死区压降和偏置的影响。
2. **电感**：在正 d 轴偏置上，对 d、q 轴分别小幅交流注入，每轴两种频率；当前 10 kHz 采样为 **250 / 500 Hz**，20 kHz 采样为 500 / 1000 Hz。按整周期同步解调电压、电流，得到基波阻抗幅值 `Z₁、Z₂`，从 `L²=(Z₂²−Z₁²)/(ω₂²−ω₁²)` 分别计算 Ld、Lq。q 轴交流均值为零，轴可能有轻微振动。
3. **候选 PI**：目标电流环带宽默认 200 Hz，限制到采样率的 1/40 以下，并限制增益范围。并联 PI 定义为 `U = Kp·误差 + ∫Ki·误差 dt`，所以 `Kpd=2πfc·Ld`、`Kpq=2πfc·Lq`、`Ki=2πfc·R`，积分每拍乘 `1/Fs`；抗饱和系数取 `2πfc`。应用后启用已识别 Ld/Lq 的交叉耦合补偿，未辨识磁链，磁链前馈保持原配置。

这采用 RL 对象的 PI 零极点抵消思路；并联 Ki 由串联 PI 的 `Ka·Kb` 转换得到，依据 [TI 电流 PI 设计说明](https://www.ti.com/document-viewer/lit/html/SSZTCG4/GUID-4EBDE243-F8EA-41D6-8930-1E6BFACE8DEE)。停机注入识别 R/L 的通用流程可对照 [TI 参数辨识说明](https://software-dl.ti.com/mcu-sdk/esd/AM13E2X-SDK/26_01_00_03/exports/docs/docs/am13e230x/motor_control/control_motor_tuning.html)；本工程使用自写 C 状态机，没有调用 TI/ST 的闭源辨识库。

电压样本由**已生效的 CCR 占空比和实时母线**重建，再投影到 d/q 轴；不是把本拍刚计算、尚未生效的电压命令当作实测电压。交流幅值法避免把未知 PWM/ADC 相位延迟直接当成电感，但仍受逆变器非线性、电流增益和采样噪声影响。结果是本控制器 d/q 定义下包含引线与功率级影响的等效参数，不能直接当成仪表测得的线间阻抗。

## 操作

先关闭 VOFA 串口占用，从 `variants/m1-mt6835/` 目录运行：

```powershell
# 只读取当前参数并停机，不发辨识注入
python tools/bench/autotune.py --out build/autotune-status

# 自动辨识、检查质量、应用候选、保存并回读验证，退出 stop/send 6
python tools/bench/autotune.py --identify --apply --save --out build/autotune

# 自定辨识电流目标（0.2–3 A，仍受当前功率口限制）
python tools/bench/autotune.py --identify --current 1.00 --apply --out build/autotune-1a
```

工具记录 JSON 与原始状态 `.npy`，独立计时器在注入超时后发送 stop。默认只查询；只有 `--identify` 注入，`--apply` 应用，`--save` 才写 Flash。也可在 VOFA 发送框逐条发送带换行的固件命令：

| 命令 | 行为 |
|---|---|
| `identify` / `identify 1.50` | 自动辨识并计算候选，结束自动关输出；不覆盖现有 PI |
| `tune apply` | 仅在待机且候选有效时应用，清电流积分器 |
| `tune save` | 待机保存当前已应用参数及现有角度校准，写后校验 |
| `tune default` | 在 RAM 恢复编译档案 PI；已保存的参数会在下次启动重新加载 |
| `stop` | 立即结束运行或中止辨识 |
| `send 7` | 参数诊断组，12 个 float + 帧尾；不要套用 24 通道总览画布 |
| `send 6` | 恢复现有 VOFA 24 通道总览 |

数字命令最多两位小数，不使用指数写法。同步修正了 VOFA 控制条的发送精度，使它发送固件接受的两位小数。

## 质量检查及适配边界

辨识时电压上限 1.5 V、目标电流默认 1.5 A；每拍检查 d/q 电流矢量 ≤1.8 倍辨识目标、机械位移 ≤0.5°、速度 ≤20 rpm、母线在配置范围且变化不超过起始值的 10%。这些**实验中止条件在 WARN 下也执行**。ADC/编码器/时序等错误会中止，`stop` 也能随时取消。

直流目标需在 10% 内且已稳定；交流基波电流幅值 ≥0.025 A、基波占交流能量至少 75%，高频感抗/阻抗 ≥15%，交流拟合电阻与直流差分电阻偏差 ≤30%。无效负根号、信号不足和越界不产生可应用结果，原 PI 保留。当前算法允许等效 R 为 0.02–10 Ω、Ld/Lq 为 2 µH–50 mH，但这不是整段范围已经实机验收；默认 1.5 V 注入不能激励所有高电阻电机，极低电感也可能超出采样分辨能力，此时应降低目标或改用合适的采样/仪器方案。

该功能自动适配 **R/L、电流 PI 和运行时母线变化**。新电机的极对数、额定电压/电流范围及安装编号仍须正确配置并重新 `cal`；不会自动推断电机型号、额定电流、磁链、转动惯量或速度/位置环参数。换电机/磁铁/相线后提高安装编号，防止沿用前一台电机的记录。

## 保存与诊断

角度校准仍是 sector 11 的 v3 记录，地址 `0x080E0000`；R/L 与 PI 的扩展记录在 `+64`，含版本、完整身份、精确角度校准、参数、FNV 校验和提交 magic。保存时输出关闭、采样暂停；保留角度校准、写后回读验证，然后重同步采样。首次旧 v3 记录仍可正常启动，扩展无效时回退编译默认 PI。重新校准的保存会删除旧电气参数扩展，之后应再辨识。

保存会擦写同一个 Flash sector；中途断电可能需要重新校准，故使用明确命令保存，不在每次运行中自动写。不要整片擦除已验证的记录。

`send 7` 下标：I0/I1 为原兼容时间/序号打包头；I2=阶段、I3=错误、I4=R、I5=Ld、I6=Lq、I7=Kpd、I8=Kpq、I9=Ki/s、I10=fc/Hz、I11=标志。标志 bit0=候选有效、bit1=存在已启用电气参数、bit2–3=保存状态（0无/1待处理/2回读成功/3失败）、bit4=候选与当前应用参数完全一致。存在旧参数不代表新候选已经应用；启动阶段 0 且已启用时，数值显示从 Flash 加载的参数。

阶段：0待机、1/2两级 R、3/4两频 Ld、5/6两频 Lq、7候选就绪、8失败、9取消。错误：0无、1母线、2电流、3运动、4激励质量、5拟合、6输入/采样异常、7时序。默认的旧 `send 0`–`send 6` 数据布局不变。
