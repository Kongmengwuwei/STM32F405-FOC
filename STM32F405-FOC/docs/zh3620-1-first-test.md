# ZH3620-1 首次实机测试清单

这份清单针对默认固件 **M0 功率接口 + TLE5012B + ZH3620-1 + 安装编号 1**。程序构建、USB/烧录、一次完整电角度校准和短时转矩输出已在实物上通过；**持续低速运行和位置控制仍未通过**，栅极波形、电流绝对比例也尚未验收。2026-09-24～25 的过程和原始结论见[校准诊断记录](zh3620-1-live-diagnosis-2026-09-24.md)。更换接口或编码器时，重新检查对应引脚、采样时序与上位机帧率。

## 1. 断电核对

- 确认实物电机确为 ZH3620-1、14 极，即 7 极对；12 槽不等于极对数。三相与 M0 三相口连接牢固，电机轴能自由转动且没有负载或会被卷入的线缆。
- 确认编码器芯片为 TLE5012B，模块供电与信号电平符合板卡要求，SPI3 的 PA0 片选及 PC10/PC11/PC12 接线和共地正确。磁铁与电机轴固定，气隙和同心度正常。
- 用万用表检查三组相间电阻接近、各相对外壳/电源无意外短路；记录实际相间电阻，不把配置中的暂定 `0.12 Ω` 当作测量结果。核对驱动器实物型号、电流采样电阻与运放增益、EG2134 输入有效电平及板上是否有硬件快速过流关断。
- 准备可调限流电源、ST-Link、USB 数据线、万用表；需要验证 PWM、死区和采样点时使用适合该电路的示波器与探头。确保能立即断电，并在上位机放好 `stop` 命令。

## 2. 烧录后先确认输出关闭

- 构建日志须显示 `port=M0, encoder=TLE5012B, motor=ZH3620_1, installation=1`。烧录默认 `build/Debug/STM32F405-FOC.elf`，核对 ELF 时间戳，避免烧错组合。旧 Flash 零点在本版 v3 中不会复用。
- 首先只给控制板逻辑供电，检查 3.3 V、复位、8 MHz HSE、168 MHz 主时钟与 USB 48 MHz。原生 USB 应枚举 CDC 口；若未枚举，先排查时钟、线缆和 PA11/PA12，不发送电机命令。
- 确认上电不会自动对齐或启动：三相功率输出保持关闭。手转轴时编码器角度在 0–360° 内连续变化，一机械圈回到起点；CRC/状态错误计数不应持续增加。编码器断开或坏帧必须使固件故障锁存并保持输出关闭，再接回后也不应自动运行。
- 给母线接限流电源，建议从 **9–12 V、约 1 A 电源限流**开始；不得超过当前固件 12.4 V 允许值。关断状态下核对 ADC 零偏与安静程度：B/C 放大器输出应在代码接受的 1.4–1.9 V 区间，静止 2048 样本方差应通过；母线遥测与万用表读数应接近。若任何项异常，停在本阶段。

## 3. 校准和极对数

- 新安装且没有有效 Flash 记录时，轴保持空载自由，发送一次 `cal`。程序先进行低边预充和 PWM 开启后的 50 ms 电流零点复核，再以 **0.45 A 电流目标、0.20 V 输出上限**正反各扫描约 4 s，整个流程约 10 s。一个电周的机械行程预期 `360° / 7≈51.4°`，往返到起点附近才保存零点。实机第一次扫描回程仍差约 5°而失败，第二次通过并写入 Flash；这说明校准**并非每次可靠**。若报 `FOC_ALIGNMENT`、`FOC_CURRENT` 或母线异常，先查原因，不连续反复 `clear`/`cal`。已有有效记录时上电保持待机，无须每次重新校准。
- 观察三相栅极输入、驱动器输出和死区；示波器测量需符合电路的接地与电压要求。核对电流采样发生在预期 PWM 窗口内，中断最坏耗时小于下次写 PWM 的截止时间。现有软件相电流保护是周期采样，不能替代硬件短路保护。
- 重新上电后应保持待机，并只加载本组合、同安装编号的校准零点。更换磁铁位置、编码器安装或三相接线后改变 `FOC_INSTALLATION_ID`，重新构建与 `cal`。

## 4. 逐级闭环

在 `send 1` 查看相电流和电角度，在 `send 3` 查看转速、目标转速与 Iq。每一步先短时观察，再用 `stop` 结束；故障后先查原因，不反复 `clear` 重试。

1. `Iq 0.05`、`Iq 0.10`、`Iq 0.20` 已完成短时实测，能进入运行并正常停止，但转角很小。`Iq 0.30` 曾使轴加速并因 100 rpm 软件限速而停机；因此不得把它当成长期运行命令。普通命令上限仍为 **0.30 A**，图片的 12 A 堵转电流不能直接用作命令。
2. `rpm 20`、`rpm 30` 在 M0/ZH3620-1 上尚未稳定。试验性提高普通上限至 0.45 A 曾出现起动后超速、速度摆动或持续停顿；该提高已撤回。下一轮先用外部仪器核实 B/C 相电流比例和极性、三相栅极波形、实际相电阻/阻力，再整定速度环。现阶段不要在 VOFA 长时间连续发送 `rpm` 目标。
3. 位置模式 `pos` 依赖尚未稳定的速度环，暂不进行实机位置或带载运行。后续通过速度环验收后，再从小角度、短时、空载试起，并每 50–100 ms 重发目标。

随时终止的条件：传感器角度跳变或 CRC 错误、三相电流波形/比例不合理、母线跌出 8–12.4 V、相电流达到 **1.20 A** 软件跳闸、速度达到 100 rpm、栅极互补波形/死区异常、板卡或电机迅速发热、异响或机械干涉。`Iq`、`rpm`、`pos` 在目标超过 200 ms 未重发时也会故障关断。`clear` 只清故障，不自动重新运行。

## 5. 上位机和需要留存的数据

VOFA+ 选择 CDC COM、Serial、2000000 baud、8N1、无流控、JustFloat，打开 DTR；USB 命令必须以真正的回车或换行结束。`send 0` 看 ADC 原始码、母线、编码器原始角度；`send 1` 看电流和电角度；`send 3` 的通道 7 为 FOC 转速、8 为目标转速、9 为 Iq。M0 以 10 kHz 发 52 字节/帧，波形软件显示流畅不等于全帧无丢失。要核查连续性，从共用固件目录运行 `python tests/capture_usb.py COM端口 --sample-hz 10000 --seconds 30`。原 `bench.py run` 使用参考电机工况，暂不用于 ZH3620-1。

每项试验记录：固件构建的四项选择、母线电压和电源限流、实际相间电阻、编码器机械角与错误计数、ADC 零偏和原始码、Iq 目标/实测、Id、速度、状态/故障码、最慢采样/写 PWM 时间、栅极示波截图及停机原因。下一步调大电流或带负载之前，应先实测相电阻/电感、采样增益与极性、持续温升及硬件快速过流路径；再按这些结果重新整定 PI 和保护值。
