# 云台工具使用说明（供其他 AI / 对话读取）

更新日期：2026-10-03。本文是当前硬件的日常操作入口；历史对话中的旧轴名称、多圈权限和参数不能替代这里的当前配置。

## 当前设备与坐标

- 项目：`D:/STM32F405-FOC/STM32F405-FOC`。
- M0 是俯仰（pitch），M1 是水平（yaw）。两轴均不能连续多圈。
- 两轴正常角度命令均为 −85°～+85°，实际行程保护为 ±90°，两侧留 5°余量。
- 单位是机械角度，相对本次上电/复位时建立的中心，不是地理方向或 IMU 姿态。编码器正方向尚不能直接解释为“向上/向右”，需要用户确认实际方向；普通操作不要重新定义零位。
- 每次复位/上电前，两轴及接线应处于机械中间、自然松弛的位置。固件在第一笔有效编码器数据处建立行程中心；停机后结构会自行移动，不能用停机后的姿态再次复位来扩大行程。
- 电流给定上限 8 A、相电流停机阈值 10 A；轨迹上限 48 RPM（288°/s），加减速 240 RPM/s。当前仍有偶发约 0.23°短暂偏移，不能保证任意外力下完全不动，也未做长期温升验收。
- 此前已完成当前负载的两轴定位、交叉保持和小角度同时动作。日常使用不需要重新烧录或电角度校准。

## 推荐入口：JSON 命令行工具

工具绝对路径：

`D:/STM32F405-FOC/STM32F405-FOC/variants/m1-mt6835/tools/gimbal_cli.py`

需要本机 Python 和 `pyserial`。本机已有依赖；换电脑可安装 `python -m pip install pyserial`。工具依赖同目录的 `dual_smoke.py`，迁移时保留两个文件在一起。

工具自动识别 USB VID:PID `0483:5740`、板卡序列号 `385C38793335`；当前端口通常为 COM8，不应硬编码假设端口永远不变。显式端口用 `--port COM8`，放在动作名前。无法唯一识别时会报错，不随意选择其他串口。

### 只读取当前状态

```powershell
python "D:/STM32F405-FOC/STM32F405-FOC/variants/m1-mt6835/tools/gimbal_cli.py" status
```

`status` 不发送运动、停机或清故障命令。成功读取时输出 UTF-8 JSON：`axes[0]` 为 M0/pitch，`axes[1]` 为 M1/yaw，各含目标/实际角度、转速、Iq/Id、母线电压、模式、运行状态、故障及告警。`ok: true` 在 status 中仅表示读取成功，不代表故障为零。

### 同时到指定角度，确认到位后自动停机

```powershell
python "D:/STM32F405-FOC/STM32F405-FOC/variants/m1-mt6835/tools/gimbal_cli.py" move --pitch 3 --yaw -3
```

默认：最多等待 8 s，两轴均在目标 ±0.2°内连续 0.3 s 后视为到位，再监控保持 1 s，最后发送停止并确认两轴退出运行。输出包含 `settled`、到位耗时、到位时/保持结束时遥测、保持期间最大偏差、`stop_confirmed`。其中 `telemetry` 是到位或保持阶段的数据；停止是否完成以 `stop_confirmed` 判断，需要停机后的实际姿态再调用 `status`。

可选 `--timeout 8 --tolerance 0.2 --hold-seconds 5`；保持时长为 0 或 0.1～60 s。正常数字最多两位小数，超过 ±85°或非有限数值会被拒绝。两轴角度必须同时提供；需要只改变一轴时，先读取另一轴的实际/目标角度，并按任务决定保留哪一个。

### 保持角度，供拍照、观测等后续任务使用

```powershell
python "D:/STM32F405-FOC/STM32F405-FOC/variants/m1-mt6835/tools/gimbal_cli.py" move --pitch 10 --yaw 20 --keep-holding
```

仅在任务明确需要后续保持时使用 `--keep-holding`。成功后串口释放，两轴仍通电保持；可由同一任务随后拍照或读状态。此时输出 `holding_after_exit: true`、`stop_confirmed: false` 是预期行为。串口释放后工具不再持续监控，固件的电流/速度/行程保护仍保留；不要把它当作无限时无人值守保持。

异常或用户 Ctrl+C 时，即使指定继续保持，工具也会尝试停机并核对状态。进程被强制终止、电脑断电或 USB 断开时，软件无法保证停止已经送达。

### 停止两轴

```powershell
python "D:/STM32F405-FOC/STM32F405-FOC/variants/m1-mt6835/tools/gimbal_cli.py" stop
```

任务完成后停止，除非用户明确要求继续保持。停止不是回零，俯仰轴会失去支撑力，结构可能下落。回到软件零位并保持应使用 `move --pitch 0 --yaw 0 --keep-holding`；这不会重新建立机械中心。

### 返回值与失败处理

- 成功退出码 0，运行失败退出码 1，命令参数错误退出码 2。运行结果为一行 JSON；参数错误由标准命令行帮助输出到 stderr。
- 移动前核对实时母线、角度、转速、状态和故障；命令后核对两轴实际接受的目标。没有 ASCII `OK` 回应，“发送了”不等于“接受了”。
- 运动中检查遥测、电流、速度和接近边界；到位后的监控保持阶段偏离目标超过 5°也会停止（主机局部窗口，固件 ±90°边界不变）；若故障、目标意外改变、未到位或遥测丢失，退出并尝试 `stop`。`stop_confirmed: false` 表示未能证明停机完成，不能报告“已经安全停机”。
- 不自动 `clear`、`zero`、复位、重试大角度或扩大限流/行程来绕过失败。先报告实际故障和停止是否确认；需要维护时按用户明确任务排查。
- 串口被占用：断开 VOFA 的串口连接，再调用工具；不要强杀其他控制进程。一次只由一个任务控制云台，避免其他对话或程序改写目标。
- 本机或具备相同硬件访问权限的执行环境才能运行此工具；只有文字交流、没有本机串口权限的 AI 只能给出命令，不能声称实际操作完成。

## 原生协议（只有集成其他软件时才需要）

USB CDC、1000000 baud、8N1、DTR 开启。ASCII 命令以真正的 `\r\n` 结束，最多两位小数：

```text
gimbal pos 10.00 -20.00
m0 pos 10.00
m1 pos -20.00
m0 hold
m1 hold
stop
```

`gimbal pos` 的第一个数是 M0 俯仰，第二个是 M1 水平，两轴共同接受或共同拒绝；单轴 `pos` 只改对应轴。位置命令持续有效，无需定时重复。关闭串口、退出 VOFA、拔 USB 都不会自动关闭电机。

遥测采用 24 个 little-endian float32，再跟 `00 00 80 7F`，共 100 字节、约 1 kHz。每轴 12 项，M0 在前、M1 在后：

`目标RPM、实际RPM、目标角度、实际角度、目标Iq、实际Iq、实际Id、母线电压、模式、状态、故障、告警`

模式 2 为位置；状态 0 待机、1 预充、2 校准、3 保存、4 运行、5 故障、6 校零、7 PWM校零。常见故障 1 编码器、8 母线、10 电流、11 超速、12 行程；告警位不等于当前故障。
