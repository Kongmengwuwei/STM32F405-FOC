# M0 有感 FOC 上板记录

日期：2026-09-23。实物为 STM32F405RGT6 驱动板、M0 通道、ZH3620-1 电机、TLE5012B 磁编码器，实验电源为 12 V 且用户设定 1.0 A 限流。ZH3620-1 的实际极对数尚未得到型号资料或磁钢计数确认；程序目前暂按 7 极对计算。

## 已实现的功能

- HSI PLL 168 MHz；TIM1 10 kHz 中心对齐互补 PWM。M0 六路栅极输入上电关闭，准备控制环不自动打开 TIM1 CCER/MOE。
- TIM1 TRGO 固定相位触发 ADC1 注入采集 B/C 相；ADC2 独立读取母线。输出关闭时采 256 组同步零点。TLE5012B 通过 SPI3 模式 1 读取角度和安全字；无效帧或过期角度使驱动关断。
- `foc_current_loop.c` 实现 d/q PI、电压矢量限幅和 SVPWM；`foc_speed_loop.c` 实现带低通滤波及抗积分饱和的速度 PI。控制周期分别为 100 µs 和约 1 ms。
- 电流、母线、采样周期、传感器状态、方向、超速及堵转保护。故障先清 TIM1 MOE，再将 PWM 引脚切回低电平 GPIO；故障锁存，不自动重试。

## 实测过程

| 阶段 | 实测结果 |
| --- | --- |
| 同步采样但输出关闭 | 10 kHz 周期约 16800 CPU 时钟，B/C 同步零点窗口跨度约 10–13 ADC 计数；TIM1 CCER=0、MOE=0。 |
| 固定磁场对齐 | 0.08 V、0.3 s 脉冲完整结束，峰值相电流约 0.54 A，输出自动关闭。 |
| 方向确认 | 0.12 V 下磁场增加 0.7 电角度，编码器在多次起始位置附近减少约 42–67 计数；暂按“正电角度对应编码器计数减少”。 |
| 一次性 q 轴电流环 | 目标 0.2 A、0.3 s、3001 次控制周期；后 0.2 s 平均 q 电流约 0.181 A，末次约 0.210 A，峰值相电流约 0.47 A，最慢回调约 23 µs；无故障并自动关断。 |
| 上电自动 60 rpm 首次试验 | 缩短定时器死区后，慢速磁场扫描的编码器变化约 −2901 计数，速度环启动；电流目标升至 0.4 A，最高速度仅约 3 rpm，后续相电流达到约 0.85 A 并触发保护。 |
| 较慢扫描复测 | 磁场以 0.14 V 扫描，约 2 s 时相电流达到约 0.81 A 而关断，编码器只变化约 40 计数。 |

**结论：低电流短时 q 轴闭环已上板验证；上电后持续 60 rpm 尚未实现。** 自动启动版本会在检查失败或保护触发时停止，不能将其视为已可持续运行的控制器。当前定时器死区编码 `0x7F` 对应约 0.76 µs；尚需示波器核实栅极和相电压波形。

## 当前待查项

1. 确认 ZH3620-1 的实际磁极数和有无减速器/机械负载。旧电机的“14 极”资料不能直接套到新电机。
2. 在确认机械自由度后核对三相相序、TLE5012B 与转子轴的固定关系，以及实际电流比例。原理图标称 1 mΩ 分流、20 倍放大，目前尚无外部电流表校准。
3. 用示波器检查 TIM1 六路输入、EG2134 输出、三相相电压、死区和 ADC 采样点。板上未见独立硬件过流关断，因此软件 10 kHz 保护不能代替硬件短路保护。
4. 找出持续转速远低于目标的原因后，再验证速度阶跃、反向、负载和长时间温升。

构建与烧录见 `vscode-build.md`。调试变量的绝对 RAM 地址会随每次链接变化，应按当前 ELF 符号表读取；运行状态 `M0_ALIGN_FAULT=3`、`M0_TORQUE_RUNNING=4`、`M0_TORQUE_COMPLETE=5`，故障位定义在 `App/Inc/foc_drive_state.h`。
