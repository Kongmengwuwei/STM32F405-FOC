# 当前磁编下的极对数与电角度自动适配

2026-10-10，M1 / TLE5012B / SPI3 与原 CS 接线不变。固件新增自动极对数、磁编方向、电角度零点的候选辨识及完整 commissioning 主机流程。编译档案的 7 极对仅作没有有效记录时的默认值，实际 Park 变换、速度电角度换算及交叉耦合补偿使用运行时极对数。

## 方案

1. 门极关闭时先完成现有 ADC 电流零偏采样，校准命令要求停机、轴速度小于 5 rpm、采样新鲜、母线在配置范围。
2. 不依赖旧极对数/零点，直接沿已知的定子磁场方向注入正电流。用慢电压积分器调节，目标在前 2.5 s 渐升，电压矢量上限 1.5 V。电流目标由使用者指定为 0.2～3 A，默认 1.5 A；每拍电流矢量超过目标的 1.8 倍、母线越界、编码器跳变/异常速度或时序错误均硬中止，WARN 也不能绕过。
3. 在 15° 电角度保持 3.5 s，再正向扫描 3 圈电角度，反向扫描 3 圈，速度 0.25 电转/s，最后静止 0.5 s。总计约 28 s。P=1 的电机单向会实际转 3 圈；必须为空载可自由转动轴，不适用于有机械行程限制的执行机构。
4. 机械角度跨 0/360° 时连续展开。每个方向丢弃第一圈电角度以避开起步/反向滞后，在剩余两圈中以 1 kHz 样本独立线性回归：`机械角 = 斜率 × 电角 + 常量`，`P = 1/abs(斜率)`。正向斜率的符号给出磁编方向。
5. 两方向必须对应同一个 1～64 范围内的整数极对数，每次估计与整数差不超过 0.15；两方向斜率符号必须相反。电角度等效 RMS 跟随残差不超过 10°；回程位置误差不超过 7° 电角度、最后采样位置范围不超过 3° 电角度。卡轴、滑步、非整数结果、不能回程或仍在抖动不发布有效候选。
6. 零点由两个方向各两圈的平均电角度偏差合成，以减小齿槽/静摩擦与扫描滞后的偏置；两个方向的平均偏差之差超过 60° 电角度仍拒绝。最后 0.2 s 的静止均值用于回程校验。此处校准的是电角度零点，机械位置命令的相对零点仍由原来的 `zero` 命令设置。
7. 成功先停机并发布候选，`sensor apply` 在短 IRQ 临界区内应用。校准探测失败保留旧校准和旧电流参数；应用新校准后禁用旧 R/L，避免将它们误用于新电机。之后用已有 [R/L 辨识与 PI 整定](motor-autotune.md)，所有阶段通过后统一保存。

极对数转角比辨识、磁编方向和电角度零点校准的通用思路也可见 [SimpleFOC 电机配置](https://docs.simplefoc.com/bldcmotor)与[FOC 初始化流程](https://docs.simplefoc.com/foc_implementation)。本工程使用独立 C 状态机，双向回归与拒绝条件为本工程实现。

## 使用

从 `variants/m1-mt6835/` 运行，先断开 VOFA 的串口占用：

```powershell
# 自动识别极对数/磁编方向/零点，应用，再识别 R/L 与整定 PI。
# 电流必须按实际电机能力设定；这里 3 A 是当前龙邱电机的校准试验值。
python tools/bench/autotune.py --commission --cal-current 3.00 --current 1.50 --save --out build/commission
```

`--commission` 隐含 `--identify --apply`；`--save` 是唯一的 Flash 写入选择。扫描和 R/L 注入分别有独立主机停止计时器。任何失败都会结束输出、保留原 Flash 记录并报告阶段/原因；R/L 失败后 RAM 中可能已应用新角度校准，应重新辨识，或复位加载原记录。退出恢复 `send 6`，不影响现有 24 通道 VOFA 总览。

固件单步命令：`autocal 3.00` → 等待有效 READY → `sensor apply` → `identify 1.50` → 等待有效 READY → `tune apply` → 阶跃验收 → `tune save`。R/L 现在两次测量共约 7.2 s；推荐使用上面的主机工具，应用/保存前后的电流验收由工具执行，失败回退旧 PI。VOFA 单步 `tune save` 是底层保存接口，本身不执行运动验收。`autocal`、`sensor apply` 都不写 Flash。`stop` 可中止任何运动阶段。

`send 8` 为 12-float 旧式诊断帧（I0/I1 为打包头）：

| 通道 | 内容 |
|---|---|
| I2 / I3 | 扫描阶段 / 错误码 |
| I4 | 候选整数极对数 |
| I5 / I6 | 正向 / 反向极对数估计 |
| I7 / I8 | 当前已应用磁编方向 / 电角度零点 rad |
| I9 / I10 | 机械角 RMS 残差 / 回程误差 deg |
| I11 | bit0 候选有效、bit1 当前已校准、bit2 候选与当前校准完全一致、bit8.. 当前运行时极对数 |

阶段：0 空闲、1 保持、2 正扫、3 反扫、4 整定、5 采样、6 READY、7 FAILED、8 CANCELLED。错误：0 正常、1 输入、2 无运动、3 非整数、4 方向、5 跟随、6 回程、7 通用中止；硬件中止用 `0x100 + FOC_FAULT_CODE` 表示，例如 `0x103` 为时序中止。

Flash v4 前缀仍为 24 字节，`poles` 高 16 位绑定原功率口/档案/磁编/安装编号，低 16 位为识别的极对数。旧 v3 只有其极对数匹配编译配置才加载；v4 接受 1～64。52 字节 R/L 扩展仍在 +64，精确绑定同一角度和运行时极对数。换实体电机、磁铁安装或相线，应更新安装编号，重新执行流程；不能根据静止的磁编读数识别已更换电机。

## 验证与边界

换回 ZH3620-1 后，在确认的 12 V 空载工况已完成新的 28 s 扫描与 R/L 串联实测，见 [ZH3620 自动整定记录](zh3620-autotune-2026-10-10.md)。下列龙邱结果是此前 26 s / 静止零点算法的历史记录，不代表当前 ZH3620 工况，也未用新算法重测龙邱。

主机测试覆盖 1～64 极对、两个方向、机械角跨零、扫描滞后、卡轴、失步、非整数、回程异常、取消、输入异常、真实 FOC 运行时电角度、母线硬中止、USB 新命令和诊断组、v3/v4 校验及 R/L 极对数绑定。龙邱 WARN/TRIP、原 M0、外环、ADC 窗口等现有测试也进行回归。

实机已烧录并完成极对数/磁编扫描：正向估计 7.01180、反向 6.92649，识别为 **7 极对**；方向 **+1**，零点 **2.673419 rad**，机械 RMS 残差 **1.11546°**（约 7.81° 电角度），回程误差 **−0.01456°**。原零点 2.678833 rad，差 −0.005414 rad。1.5 A 扫描残差约 2° 机械角，被拒绝；3 A 时降低到约 1.12°。残差同时包含电机跟随误差和磁编/安装误差，不能据此归因或生成磁编非线性补偿表。

**当前完整串联实测未验收**：本次采样换算母线约 **20.04 V**，与上次用户确认的 12 V 不一致，待确认实际电源。新校准后的 1.5 A R/L 流程在第一 DC 级被拒绝，均值约 0.74976 A、每拍 RMS 纹波约 0.14734 A，超过现有稳态质量阈值；未应用新的 R/L、未保存新校准。原 Flash 记录保留。先前 R/L 在 12 V 的成功记录保持为历史证据，不作为本次整串联成功的依据。详见 [本次结果 JSON](data/motor-sensor-autocal-20261010.json)。

固定 TLE5012B 与一对一直相连的机械轴，可以自动识别上述换相关系和电流环参数。仍需给出额定电压/电流、试探电流上限和机械行程；磁链/KV、惯量、摩擦及速度/位置环还需要其他辨识实验。磁编偏心/谐波误差的高精度补偿需要额外角度参考或经过验证的充分采样，不能把电机齿槽与负载角误当作传感器误差。因此适配覆盖的是具有足够可测响应的三相 PMSM/BLDC；不保证任意未知电机均能通过现有电压/电流与采样窗口。
