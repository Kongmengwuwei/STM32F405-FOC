# 两路腿部关节控制与调试（2026-10-14）

采用用户选定的可靠上方机械姿态为两路 0°，向下回转为正，软件目标范围 0°～110°。M0 正方向对应磁编角度递增，M1 正方向对应磁编递减，电机轴到关节减速比 7∶1。基准原始记录见 [leg-boundaries-20261014.json](data/leg-boundaries-20261014.json)，固件匹配常量位于 `dual/leg_reference_config.h`。

## 使用

控制板重启后禁止位置输出，不能用电机单圈读数自动猜测关节圈数。先将两路放到可靠 0° 机械姿态并支撑，待电流偏置采集完成，再发送 `leg home`。该命令校验磁编单圈读数接近记录值（人工确认可靠止点后允许±14电机度，即±2关节度，以容纳实测回零差异；不增加通电行程），然后将当前连续电机角度定义为关节零位；不会自动启动。

```
stop
send 0
leg home
limit 10
leg rate 45
leg pos 2 2
```

位置命令需要至少每 500 ms 更新一次；VOFA 面板每 50 ms 更新。`leg hold` 请求两路原位保持，也需要后续位置刷新。`m0/m1 pos` 同样使用新的关节角度，`m0/m1 zero` 禁用，机械零位统一通过 `leg home` 建立。暂停、清除故障均不自动恢复驱动。

本次机械路径仅按用户确认的 `q0=q1` 同步路径进行试验；不同角度组合需五连杆运动学与可达性约束。建议实际运动留量 2°～108°。

## 保护与当前调参

当前用户要求指令电流最大/默认10 A；相电流或dq向量达到11 A立即关闭两路，11 A仅为瞬态故障门槛。母线保护保留原范围，500 ms位置命令失联关闭两路。运行超速180电机RPM，并保留5 ms平方速度统计，防止正反振荡被有符号平均抵消。旧阈值见 [原阶段提案](data/dual-leg-workspace-proposal.json)，当前修改和分级顺序见 [加速提案](data/dual-leg-fast-plan-20261014.json)。关闭输出的被动角度继续采集，CRC和连续性检查保留。

目标严格限制0°～110°；运行实际偏离到−1°/111°以外持续20 ms停机，超过−2°/112°立即停机。在0°和110°处抑制向范围外施力。目标误差超过2°、接近电流饱和且2秒没有0.2°进展才判堵转。

位置轨迹采用150电机RPM/s加减速；`leg rate 10/30/45` 分别约8.57/25.71/38.57关节度每秒。默认启动速度上限30电机RPM，VOFA面板默认选择已验证的45 RPM，并在点击更新时先发送rate再发送位置；rate可在保持期间改变，不清积分、不释放输出，也不代替位置命令刷新。固件保留10～60 RPM的研发输入范围，但60 RPM已触发超速、未通过，不作为可用档位展示或推荐。

控制修正：位置观测与关节目标换算统一到10 kHz，避免旧1 kHz位置与新角度混算；近目标低增益PD，超过0.3关节度偏差增加连续额外刚度以克服静摩擦。积分死区0.2关节度，按实际电流限幅抗饱和，最大偏置3 A。静止速度反馈5 ms/阻尼0.025 A/RPM/电流变化120 A/s；运动时采用2 ms反馈、0.04 A/RPM阻尼和240 A/s电流变化。实际速度超过轨迹上限20 RPM时增加制动，180 RPM硬超速仍保留。

两路电流环和PWM写入优先；M1的1 kHz机械外环错开M0约500 μs，角度观测和电流环仍为10 kHz。最终实测PWM最小写入计数3449/1521 tick，高于600 tick截止线；ADC IRQ峰值16072 cycles，约95.67 μs，100 μs周期余量约4.33 μs。未来五连杆运动学应在主循环/任务中计算，通过目标命令交给控制环，不能继续堆入当前ADC ISR。

## 从当前位置继续、重力与VOFA

只要没有重启、编码器连续采样且正常组基准标志有效，可在合法行程内从当前姿态 `leg hold` 或 `leg pos`，无需重新回零。已实测断开/重新打开串口、人工恢复行程内姿态、清除超速后继续控制，全过程没有重定义零位。`clear` 不自动驱动，UART/速度等持续采样故障保留有效圈数；ADC/SPI/数值/PWM时序等使采集失效的故障则取消基准，需要重新回到可靠止点。断电/重启期间轴可能转动，电机单圈编码器不能区分约51.43关节度的整圈别名，因此冷启动无法保证任意姿态绝对定位。

用户确认零位在上方，关闭输出就会自然下落。串口失联、停机或保护触发后不保持扭矩，必须支撑机械腿。断电前后的机械圈数基准不能自动恢复；输出关闭后的角度仍会采集，越出软件范围不会冻结采样，但需要手动恢复到可控制姿态后才能启动。

VOFA配置显示0°～110°关节坐标和基准状态，提供可靠边界回零、同步目标、原位保持、设置电流上限、停止及清除故障。回零、控制使能、目标角度不随GUI重启恢复；配置窗口只保存位置/尺寸。正常组24通道保持1000 Hz/100字节帧，告警通道11/23中的`0x400000`表示基准有效，面板单独解码该位。诊断组1通道22：0未回零、1示教、2示教失效、3已回零。

Qt离线验证通过未回零/旧数据禁止启动、边界输入、同步刷新、诊断组停止、原位保持和仅保存几何状态。当前离线平台无法截图，未声称完成真实VOFA窗口的视觉检查。安装脚本备份现有配置后复制新面板，重开VOFA即可加载。
