# 用 VOFA+ 查看 USB 遥测

这份说明按项目默认的 **M0 + TLE5012B + ZH3620-1** 遥测格式编写，并在本机用 **COM8、VOFA+ 1.3.10** 验证了 USB 收数与图表。USB 连通并收到数据，只证明通信和遥测正在工作；电机驱动与闭环控制还要按[首测清单](zh3620-1-first-test.md)单独验证。

## 打开连接

1. 用数据线连接开发板的原生 USB 口，给板正常供电，确保程序没有停在调试断点。
2. 在 VOFA+ 的“协议与连接”中选 **JustFloat → 串口 → COM8**；串口参数选 **2000000、8 数据位、无校验、1 停止位、无流控**。USB CDC 的波特率是上位机端设置，不决定 USB 线速。
3. 点击左上方的连接按钮，再打开下方的 **DTR**。右侧出现 `I0` 到 `I11` 且数字持续更新，就表示收到了固件的二进制遥测。若 COM 号发生变化，改选新端口。
4. 需要完整的电压/角度和电流环双标签布局时，点击画布右上角 `⋮` →“载入...”，选同目录的 [vofa-foc-current.tabview.json](vofa-foc-current.tabview.json)。只想在当前窗口添加电流环标签时，选 [vofa-current.tab.json](vofa-current.tab.json)；原来的单独双图标签仍可从 [vofa-foc.tab.json](vofa-foc.tab.json) 加载。

VOFA 的接收文本区显示乱码是正常的：固件发送的是 JustFloat 二进制帧，不是文字。连接时 COM8 被 VOFA 独占，其他串口软件须先断开 VOFA 才能使用它。

## 当前图表怎么看

在下方发送框输入 `send 0`，保持右侧换行选项为 `\n`，点击“发送”。这条命令只选择**第 0 组遥测**，不会启动电机。当前布局的两张图分别绑定：

| 图表 | VOFA 通道 | 第 0 组含义 | 纵轴 |
|---|---|---|---|
| 上图 | `I7` | 母线电压 `v_bus` | 0–20 V |
| 下图 | `I8` | 编码器原始机械角度 `angle_raw_deg` | 0–360° |

本机连接后已看到母线约 **11.37–11.39 V**，角度约 **7.7°**，两张图也持续绘制。用手缓慢转动未使能的电机轴时，可观察角度是否变化；跨过 360°/0° 时曲线会跳回起点。

`I0`、`I1` 装的是按位编码的时间、状态和序号，不适合直接当普通浮点曲线。`send 1`、`send 2`、`send 3` 会改变 `I2`–`I11` 的含义；切换后这份布局的 `I7`、`I8` 标注不再适用。各组通道表见[台架工具说明](../variants/m1-mt6835/tools/bench/README.md)。

若数字有变化而图像暂时看着平直，先看纵轴量程：静止时电压和角度本来就接近常数。这个布局的角度轴覆盖完整一圈，小幅手动转动只会表现为细小变化。

## 在同一网格比较目标和实际电流

打开“FOC 电流环：目标与实测 Iq”标签，在发送框发送 `send 3`，换行仍选 `\n`。这个命令只切换遥测，不会使能电机。单张网格图同时显示 `I2`（目标 `Iq_ref`）和 `I9`（内部计算的实际 `Iq`），共用 **-0.6～+0.6 A** 纵轴，便于直接看跟踪误差。当前实机已验证 COM8 收到第 3 组数据并实时刷新图表；待机时目标为 0 A，目标线可能与 0 轴重合，实测线会在零附近波动。

点击回“FOC 电压与角度”标签后，发送 `send 0` 才能让它的 `I7`/`I8` 再次对应母线电压和原始角度。**切换标签本身不会改变固件的遥测组。**

观察通电电流环时，`Iq` 目标必须每 **50～100 ms** 重发；固件在超过 **200 ms** 未收到新目标时会报 `FOC_UART` 并关断 PWM。因此 VOFA 手动发送一次 `Iq 0.10` 只能看到短暂响应，不能用它维持电机运行。测试结束发送 `stop`；故障后先检查原因，再在传感器和母线有效时使用 `clear`。目前仅完成空载 `±0.10 A`、`±0.20 A` 的短时内部跟踪验证，实际相电流绝对值还没有外部标定。

### 用 VOFA 连续发送电流目标

1. 确认 VOFA 左侧为 `JustFloat`、`COM8`（或实际端口）、`2000000` 波特率，底部发送换行为 `\n`，串口已连接。先普通发送一次 `send 3`，使电流图上的 `I2`/`I9` 对应目标/实测 `Iq`；切换图表标签本身不会切换遥测组。
2. 点击右下角 **发送(S)** 右侧的小箭头，在弹出的菜单中把“发送后延时(ms)”设为 `100`，“重复次数”保持 `-1`。菜单顶部的“连续发送”是**发送模式开关**：选中后，主按钮显示“连续发送(S)”；此时尚未开始发送。
3. 在底部发送输入框只填写一行 `Iq 0.10`（区分大小写，`Iq` 后有空格，单位 A），再点击主按钮“连续发送(S)”才会开始每 100 ms 重发。按钮变为红色“终止”代表正在重发。电机可能持续加速，应盯着电机轴和 `I2`/`I9` 曲线，在短时试验结束前点击红色“终止”。`Iq -0.10` 可测试反向；请在轴空载、可立即断电的条件下试验。
4. 结束时先点红色“终止”，再从小箭头菜单取消“连续发送”，将输入框改成 `stop` 并普通发送一次。若已报故障，先查明原因，再发送 `clear`；`clear` 只清故障，不会自动启动电机。

当前 ZH3620-1 首测固件接受的普通 `Iq` 命令范围为 **-0.30～+0.30 A**、最多两位小数。电流命令控制的是转矩，空载轴可能继续加速，不能当作定速命令。**持续发送 `Iq 0.30` 已实际触发 100 rpm 软件超速故障 `FOC_SPEED`（故障码 11）；故障锁存后再发 `Iq` 无效，须先停发、待轴停稳并排除原因，再发 `clear`。** 已完成的是短时 `±0.10 A`、`±0.20 A` 跟踪测试，尚未用外部仪器标定实际相电流。
