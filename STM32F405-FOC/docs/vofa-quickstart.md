# VOFA+：连接、命令与监控

**当前默认双轴云台固件请使用[双轴命令与专用界面](vofa-gimbal.md)**：`m0 pos 10`、`m1 pos -10` 分别设角度，`gimbal pos 10 -10` 同时设两轴，`stop` 关闭两轴。固定 24 通道 / 1 kHz，M0 角度 I2/I3，M1 角度 I14/I15；载入 `vofa-gimbal.tabview.json`，时间间隔 1 ms，不发送 `send 6`。以下为历史单轴台架模式，通道含义与当前双轴不同。

## 历史单轴台架总览（FOC_DUAL=OFF、FOC_GIMBAL=OFF）

当前固件默认发送 `send 6`：24 个普通 float32 加 JustFloat 帧尾，共 100 字节/帧。M0 默认每 4 个 10 kHz 控制周期发一帧，即 2.5 kHz；电流环仍是 10 kHz。`send 0`～`send 5` 是兼容台架采集工具的 12 通道旧组，切到旧组时本页总览通道名不再适用。

## 连接和载入画面

1. 给板子和驱动正常供电，用数据线连接**原生 USB**。程序不能停在调试断点。
2. VOFA+ 选 **JustFloat → 串口 → 当前 COM 口**，设 `1000000`、8N1、无流控，连接后打开 **DTR**。COM8 是此前本机端口号，换 USB 接口后以设备管理器所见为准。CDC 的波特率设置不决定 USB 物理速率。
3. 在画布菜单中载入 [24 通道总览布局](vofa-overview.tabview.json)；[配置](vofa-overview.config.json)与[通道名](vofa-overview.channels.json)也在同目录。若自定义数字卡片未显示，把 [FOCOverview 控件](vofa/widgets/FOCOverview/FOCOverview.qml)所在目录复制到 VOFA 安装目录的 `plugins/widgets/` 后重启。旧的 CSV 表头可能覆盖中文通道名，需在 VOFA 中重新导入通道清单。
4. 在发送框单次发送 `send 6`，结尾选真正的 `\n`、`\r` 或 `\r\n`。二进制接收区出现乱码属正常；24 张卡片和三张网格图应刷新。

VOFA 占用串口时，Python 采集工具不能同时打开同一个 COM 口。使用工具前先在 VOFA 断开。切换画面标签本身不会切换固件的 `send` 组。

## 常用命令

| 命令例子 | 作用 |
|---|---|
| `cal` | 首次安装或改变相线、磁钢、编码器后，轴能自由转动时做电角度校准；成功后保存到 Flash |
| `Iq 0.10` | 请求 q 轴电流 0.10 A；电流模式，正负代表转矩方向 |
| `rpm 30` | 请求 30 rpm；速度闭环 |
| `pos 15` | 请求软件零点后的 15°；位置闭环，多圈角度可用 |
| `zero` | 停机时将当前角度定义为 0° |
| `stop` | 关闭功率输出并清除运行目标 |
| `clear` | 清除历史告警；运行中不会停止电机 |
| `send 6` | 选择 24 通道总览；不启动电机 |

`WARN` 是当前默认策略：目标只需发送一次，直到新命令或 `stop`；断开 VOFA、拔 USB 或停止重复发送都不会关闭 PWM。VOFA 若显示红色“终止”，先结束旧的连续发送，再用普通单次“发送”，避免旧命令反复覆盖新命令。`Iq 0` 是零转矩请求；`rpm 0`、`pos 0` 仍保持闭环，均不能替代 `stop`。电流模式下空载电机可持续加速；发送运动命令前先确认轴、负载和供电条件。所有电流数值目前是板上 ADC 的标称换算，尚未经外部仪表标定。

## 总览通道

| 序号 | 内容 | 单位/解读 |
|---:|---|---|
| 0 / 1 | 目标 / 实际转速 | rpm；位置模式下目标转速由轨迹产生 |
| 2 / 3 | 目标 / 实际位置 | 软件零点后的连续机械角度，° |
| 4 / 5 | 目标 / 实际 Iq | 转矩轴电流，A |
| 6 / 7 | 目标 / 实际 Id | 磁链轴电流，目标当前为 0 A |
| 8 | 母线电压 | V |
| 9 / 10 | Ud / Uq | 控制器输出电压，V |
| 11 | 控制模式 | 0 电流，1 速度，2 位置 |
| 12 | 运行状态 | 0 待机，1 预充，2 校准，3 保存，4 运行，5 故障，6 校零，7 PWM 校零 |
| 13 | 故障编号 | 0 表示无故障 |
| 14 / 15 | 告警位掩码 / 最近告警 | 历史告警非零不等于已经停机 |
| 16 | 命令拒绝次数 | 语法或状态条件不满足时增加 |
| 17 | 电压可用比例 | 饱和缩放比例；待机时可为 0 |
| 18 | 斜坡转速 | 外环当前实际使用的速度参考 |
| 19 | 速度环误差 | 通道 18 减通道 1 |
| 20 / 21 | 位置误差 / Iq 误差 | 通道 2−3、通道 4−5 |
| 22 / 23 | 设备时间 / 采样序号 | 低 24 位，分别回绕 |

总览同时显示转速、位置和 Iq 的目标与实际曲线，以及所有数值卡片。观察快速电流阶跃时，可发送 `send 5`，此组 `I2` 为目标 Iq、`I9` 为实测 Iq，但必须切到相应旧布局或重设通道名；它的窗口平均**只用于遥测**。各兼容组的完整字节表见[台架工具说明](../variants/m1-mt6835/tools/bench/README.md)。

先前在约 12 V、空载下，总览和三张图已验收；后续带塑料臂短测与定位提速见[最新性能记录](position-speedup-and-foc-roadmap-2026-09-28.md)。历史总览测试出现过少量串口记录缺点，因此看波形时需同时看设备序号；串口图形流的缺点不等于电流环漏执行。
