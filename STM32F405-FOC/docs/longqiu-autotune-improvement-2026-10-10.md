# L4225 自动整定：开源方案对照与改进实测

当前电机已确认为龙邱 L4225-6S420-A，12 V、空载、M1，磁编仍为 TLE5012B / SPI3 / PA0。改进固件已烧录、保存参数并验证复位加载。当前默认构建身份为安装 4、`0x1314`；旧的安装 4 小电机档案 `0x1214` 不会再被误加载。

## 退步原因与开源项目的做法

上次未知电机测试沿用了 ZH3620 FREE_SHAFT 档案，速度参考斜坡只有 1500 rpm/s、定位加速度 1200 rpm/s、定位速度上限 90 rpm；L4225 原配置分别为 15000、10000、240。旧兼容规则还把速度 Kp 乘以 `自动电流Kpq / 编译电流Kp`，Ki 乘其平方。上次 Kpq=0.057 时，速度 Kp 实际约 0.0114、Ki 约 0.0975。这不是转动惯量辨识，不能可靠适配电机。电流 Kp 同时取决于电感和目标带宽，不能单独代表内环速度。本次恢复 L4225 档案，并删除该比例缩放规则。

研究的是 ODrive **公开 v3.x 固件**，不是 Pro/S1/Micro 的非公开现行实现；公开仓库说明 v3.x 已不再积极维护。当前官方文档只用于核对控制结构和单位。[ODrive 仓库说明](https://github.com/odriverobotics/ODrive)

| 项目 | 实际方法 | 本工程采用的原则 |
|---|---|---|
| ODrive 电气辨识 | 固定定子坐标，以电压积分器升到目标电流测 R；正负电压交替、累计电流变化测 L；对信号、电压和拟合结果检查 | 实际 PWM 电压、受限激励、采样离散模型、失败不发布有效参数 |
| ODrive 电流 PI | `Kp=ωc·L`、`Ki=ωc·R`；带宽配置单位是 rad/s | 本工程 fc 用 Hz，明确 `ωc=2πfc`，不漏乘也不重复乘 2π |
| ODrive 磁编校准 | 电气校准后，用电流控制的开环旋转磁场正反扫描，检查磁编行程并平均偏置 | 磁编候选与电气参数分开发布和绑定，保留正反向一致性检查 |
| VESC | 在限定电流内选择辨识激励，平均多次样本，以短脉冲测 L；退出测量时恢复临时改过的参数 | 增加重复测量、结果一致性和应用后的回退快照 |

对应一手实现：[ODrive motor.cpp](https://github.com/odriverobotics/ODrive/blob/master/Firmware/MotorControl/motor.cpp)、[带宽单位定义](https://github.com/odriverobotics/ODrive/blob/master/Firmware/odrive-interface.yaml)、[encoder.cpp](https://github.com/odriverobotics/ODrive/blob/master/Firmware/MotorControl/encoder.cpp)、[VESC mcpwm_foc.c](https://github.com/vedderb/bldc/blob/master/motor/mcpwm_foc.c)。查阅日期 2026-10-10，链接指向公开 master。

ODrive 的位置 P、速度 PI 与电流 PI 是分开的；惯量/负载影响外环。它也不是测出 R/L 就自动得到任意电机、任意负载的速度和位置环参数。[官方控制结构说明](https://docs.odriverobotics.com/v/latest/manual/control.html)

## 本次实际实现

保留本板已验证的双频注入，不直接搬用别的功率板逐拍方波。逐拍 L 测量强依赖 PWM/ADC 生效相位；这台 F405 的双分流、ADC 窗口、CCR 流水线与 ODrive/VESC 不同。所有公式和状态机为本工程实现，没有复制外部项目代码。

1. **两次电气辨识**：每次为两级差分 DC 电阻、d/q 各两频电感，合计约 7.2 s。第二次 AC 幅度为第一次的 75%，DC 电流不提高。两次 R 相对差必须 ≤15%，Ld、Lq 各 ≤20%，相对差分母取两次均值。通过后平均 R/L，再计算 PI；不一致报 `IDENT_REPEAT=8`，候选无效。
2. **离散模型**：使用已生效 CCR 与实时母线重建电压。以同步解调阻抗幅值计算理想零阶保持 RL 模型，而非连续公式近似：
   `|Z|² = Rac² + B·(1−cos Ω)`，`B=2·Rac²·a/(1−a)²`，`a=exp(−Rac/(Fs·L))`。
   两频求 B/Rac，再反求 L。恒定采集延迟在幅值比中消除；真实逆变器压降、PWM 波形及采样增益仍会影响等效结果。AC/DC R 一致性和基波能量等原检查保留。
3. **电流环整定**：当前目标 fc=200 Hz，Fs=10 kHz，上限 Fs/40，`Kpd=2πfcLd`、`Kpq=2πfcLq`、`Ki=2πfcR`，启用已测电感的交叉耦合补偿。200 Hz 是设计目标，没有宣称实测闭环带宽正好为 200 Hz；磁链前馈未新增辨识。
4. **电流阶跃验收**：应用候选后，主机先采待机噪声，再发默认 +0.2/−0.2/+0.2 A，持续 50/100/50 ms，减少净加速冲量。使用设备时间戳、1 ms 尾随平均统计 T90/超调，同时记录原始电流峰值和原始稳态标准差。三段 T90 必须 ≤15 ms、平均后超调 ≤35% 步幅、末段均值误差 ≤10% 幅值。待机 d/q 噪声协方差迹的平方根必须 ≤25% 幅值；扣除该旋转不变噪声方差上界后，额外纹波标准差必须 ≤15% 幅值。扣除后为零只表示未分辨出额外纹波，不表示电流绝对无纹波。
5. **应用与回退**：`tune apply` 先在 RAM 备份旧 PI 及启用状态。验收失败后主机停机并 `tune rollback`，读取备份标志确认回退。锁存故障时也能恢复参数，故障和关闭输出状态保留。`sensor apply`/旧 `cal` 使快照失效，避免回退到另一组电角度下的参数。

阶跃中每个遥测帧均检查未滤波电流矢量 ≤0.8 A、|速度|≤120 rpm、母线相对起始变化≤10%、无故障/告警/非有限值；丢帧和采样间隔异常拒绝验收。独立主机超时计时器发送 stop。此验收器目前用于本分支的 10 kHz、USB divider=2 构建，不是任意采样率的通用台架。

额定电流、电压范围、功率板能力仍须正确配置。本流程不猜测电机型号/连续额定电流，不自动提高实验电流。`--accept-current` 可指定 0.2–0.5 A，且被 `--current` 上限约束；较大阶跃可能因自由轴加速触发上述中止条件。

## 12 V 实测

最终保存并复位加载的参数：

| 参数 | 数值 |
|---|---:|
| 极对数 / 方向 / 电角度零点 | 7 / +1 / 4.427292824 rad |
| 等效 R | 0.123902604 Ω |
| Ld / Lq | 26.789 / 44.284 µH |
| Kpd / Kpq | 0.03366356 / 0.05564892 V/A |
| Ki / 目标 fc | 155.70061 V/(A·s) / 200 Hz |

最终自动流程双次辨识、阶跃、RAM 回退与再应用均通过。保存状态为 2，Flash 身份为 `0x13140007`，前缀与扩展 FNV、magic、角度精确绑定校验通过。复位后参数逐项保持一致，电流验收再次通过，T90=6.6/6.0/6.4 ms，末段均值误差≤4.6 mA；待机电流噪声矢量标准差约 33 mA。该 T90 使用 1 ms 尾随平均，遥测分辨率 200 µs，不能视为仪器测得的频域带宽。

| 速度工况 | 本次最终参数 | 原龙邱历史配置 |
|---|---:|---:|
| +300→−300 rpm T90 | 47.6 ms | 47.6 ms |
| −300→+300 rpm T90 | 48.0 ms | 47.6 ms |
| 两次反向持续到位时间 | 62.0 / 61.6 ms | 52.4 / 62.0 ms |

速度使用相同的 20 ms 尾随平均；到位要求 ±15 rpm 内持续 100 ms。原配置历史数据来自[动态响应实测](longqiu-dynamic-response-2026-10-10.md)，安装编号/磁铁零点不同，不是严格同安装 A/B。另在本次同一零点与外环配置下对照原电流 PI 0.20/80 与初次自动候选，±60 rpm 反向 T90 分别为 23.6/25.2 和 23.6/23.2 ms，未观察到自动 PI 明显拖慢换速。

最终 `[+5°,−5°,0°]` 定位 T90=38.0/32.0/20.8 ms；持续进入 ±0.5° 的到位时间为 38/174/20.8 ms，最大超调约 0.647°。此前另一组测量/起始角度下，±5° 超调达到约 1.09°、到位约 250 ms。因此只报告该工况结果，不把快速 T90 当成所有角度均能快速稳定。

**低速纹波、小角度阻力与位置超调仍存在。** ±10 rpm 在原电流 PI 与自动 PI 下都出现明显纹波；恢复正确外环档案解决了主要换速迟缓，但当前没有惯量、摩擦/齿槽或磁编偏心补偿的自动辨识。ZH3620 的旧比例缩放已移除，其外环需重新验收，不能沿用旧报告作为新版动态证据。

本次首次磁编扫描因回位误差约 2.8° 被拒绝；相同 3 A 重复扫描通过，没有放宽回位检查。验收开发中，原始单帧峰值/固定原始纹波阈值会误判小电流测量噪声；改为上述明确滤波与噪声底统计后再完成最终流程。较大 0.5 A 阶跃曾触发 120 rpm 中止，未提高保护边界、未据失败结果保存。原始失败与通过记录均保留。

最终状态：12.03 V，IDLE、PWM 关闭，故障/告警/命令拒绝均为零，恢复 VOFA `send 6`。电流绝对比例未经独立仪表标定；仅实机验证 12 V 空载，18/24 V 是模型测试。实测汇总见[data JSON](data/longqiu-autotune-improvement-20261010.json)，本机原始记录在 `build/longqiu/odrive-improved-20261010/`。

## 使用

当前磁编安装已校准，可从 `variants/m1-mt6835/` 目录运行：

```powershell
# 只读参数并停机
python tools/bench/autotune.py --out build/status
# 电气重复辨识、应用、阶跃验收、保存
python tools/bench/autotune.py --identify --current 1.50 --apply --save --out build/tune
# 更换电机/磁铁/相线后，提高安装编号并烧录，再完整校准
python tools/bench/autotune.py --commission --cal-current 3.00 --current 1.50 --save --out build/commission
```

3 A 是当前 L4225 扫描实测上限，陌生电机须按其允许电流设置。使用前断开 VOFA 串口。`--apply` 和 `--save` 自动验收电流；速度/位置验收另用 `longqiu_dynamic.py`，不能由电流验收推断外环通过。VOFA 的 `tune save` 是底层直接保存接口，只有主机流程执行了上述阶跃验收。上电仍只读参数并校电流零偏，不自动旋转。

构建：`cmake --preset Debug-local` / `cmake --build --preset Debug-local`；显式安装 4 也可使用 `Debug-installation4-commission`（本机工具链用 `Debug-commission-next-motor`）。现有 M1 和磁编引脚未改。

`send 7` 帧布局不变；I11 新增 bit5=双次辨识一致性通过、bit6=存在可回退的 RAM 快照。错误码新增 8=重复测量不一致。复位加载阶段候选为空，所以 bit0/bit5 为零，bit1 表示已加载有效参数。
