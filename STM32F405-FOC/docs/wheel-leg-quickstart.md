# 轮腿 VOFA 操作

面板名称为“轮腿 · 直观控制”。USB串口COM8，1000000波特率、JustFloat，启用DTR。连接后自动读取状态，电机保持关闭。

## 每次重新上电

1. 支撑腿部，将**两根主动杆都放在原上止点向行程内回转约0°～40°的区域**。不必贴紧止点，放在约5°～20°处更容易避开零点回差。
2. 点击 **① 恢复腿部位置**，确认所在区域。面板显示恢复出的当前关节角，**当前位置不会被设为0°**。若显示小负角，保持输出关闭，手动向行程内挪动，直到两路均在0°～110°内。
3. 选择“关节角度 · 两路同步”，输入目标，点击 **② 移动到目标**。建议目标2°～108°。当前默认快速120电机RPM，也可选择正常60或慢速10 RPM。
4. 改目标后点击 **② 更新目标**。到达目标后会持续保持；结束点击 **停止输出**，同时支撑腿部以免重力下落。

同一次通电且位置跟踪有效时，可从行程内当前位置直接继续控制；重复点击恢复位置不会改零位。断电或采样故障使圈数失效后，才需回到上述区域恢复。不要在任意未知姿态确认区域。

## 为什么只能在零点附近恢复

磁编位于电机轴，7∶1减速后，磁编一圈对应关节 **51.43°**。已知当前位置落在宽度小于51.43°的区间内，即可选择唯一圈数。新版使用原零位附近−2°～40°的计算窗口，人工放置区域为0°～40°；−2°仅容纳原基准附近的回差，不扩大驱动行程。

例如10°与61.43°可能给出相同磁编读数，因此不能从整个0°～110°行程任意位置冷启动识别。这里的角度相对已保存的零位，回差与安装零偏仍会影响实际精度。

## 足端定点控制

当前板上已有主动杆几何标定，正常上电无需再次标定。恢复位置后选择 **足端位置 · x/y毫米**，可以先“填入当前位置”，再输入目标x/y或在图中点选，点击移动。坐标原点为两固定轴中点，x向右、y向下，单位mm；目标到达后持续保持。

足端慢速/正常/快速为20/200/400 mm/s，配套电机上限10/60/120 RPM，电流指令上限10 A。新安装或负载变化后，先用慢速小位移确认。可达域预览不包含车架与杆件三维碰撞检测；目前实物验证以两路同步路径为主。

只有改变磁铁、杆件或减速器安装，或需要重测物理零偏时，才操作“首次：标定主动杆方向”：先恢复位置，保持通电与输出关闭，手动把两根主动杆摆成竖直向下并固定，固定轴连线应水平，再标定并保存。保存会使圈数失效，完成后回到0°～40°区域恢复一次。

## 常见提示

- **磁编初始化失败／M0或M1无有效应答**：电机保持关闭；检查提示对应磁编的供电和SPI接线，排除后重启。此时刷新只读取诊断，不能通过清故障强行启动。
- **位置未识别**：按前两步确认区域、恢复位置。不要发送旧版回零命令代替。
- **按钮不亮，但已显示关节角／姿态示意**：查看按钮下方具体原因。已知角度会继续显示，即使尚不满足驱动或足端解算条件。
- **已识别角度，请手动移入0°～110°行程**：识别已成功，显示角度尚在驱动区间外。支撑并手动移入，无需重设零位。
- **M0/M1读数不在零位附近识别窗口**：检查是否确实在原上止点向内0°～40°、机构是否静止。不要在其他区域强制确认。
- **需要更新固件**：面板与固件版本不配套；新版会检测位置恢复功能位，避免向旧固件误发命令。
- **目标或轨迹不合法**：检查可达域、限位和死点提示；更新被拒绝时继续保持旧有效目标。
- **故障**：先支撑、排除具体原因，再清除故障。不会自动重启；采样故障后重新恢复位置。

关闭其他串口工具和旧面板的发送循环。安装新版后，重新打开VOFA加载面板。

## 验证记录

2026-10-16最新版已烧录；45个C配置、7套Python及VOFA交互回归通过。近零区域恢复不改保存零位，烧录前后电角度与几何标定144字节一致。

最新实物完成x=0、y=100↔200 mm的10/45/60/90/120电机RPM分级往返与运动中反向，全程无故障，用户确认没有明显高频振动或噪声。120 RPM档两个方向进入双轴±1°约1.32 s／2.57 s；推算足端稳态误差最大约0.66 mm，没有独立足端测量。详见[快速反向修正与曲线](fast-reversal-fix-20261016.md)。

FOC仍10 kHz、外环1 kHz、前台轨迹200 Hz、遥测50 Hz；保留10 A命令上限和180 RPM保护。其他横向路径尚未实物验证。停止输出后机构可能受重力落出行程：若位置仍已识别，只需支撑并手动移回0°～110°，不必重复回零。
