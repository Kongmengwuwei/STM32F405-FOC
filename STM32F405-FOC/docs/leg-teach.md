## 最终采用的控制基准（用户最新指定）

以当前更可靠的 B 机械边界为两路关节 `q=0°`，朝原 A 回转为正方向，回转 **110°** 定义另一侧软件边界。另一侧软件边界由连续电机角度计算，不要求主动杆垂直向下，也未通过通电驱动到该位置。

设 `U0/U1` 为本次持续示教会话中的电机多圈角度：

## 采集方法与验证

固件命令 `leg teach` 在停止状态进入锁定示教模式：两路桥始终关闭，持续以 10 kHz 读取磁编并处理 0°/360° 跨圈。该模式拒绝位置、保持、电机校准、软件置零、clear 和重复 teach。`stop` 保留累计圈数；`send 0/6` 在示教时返回诊断组，避免上位机误认正常驱动数据。`send 2` 提供含两路 A 起点的机械示教诊断。

采样超过 300 μs 间断、无效角度或单次角度跳变会使示教记录失效并关闭采集；本次允许的手动累计量上限为每路 ±120° 关节角。该示教范围不改变正常驱动的 ±2.5° 目标和 ±3.8° 实际位移保护。

真实硬件已验证八类驱动/重置命令被拒绝、两路桥持续关闭、故障为零，A 静止漂移约 ±0.003° 关节角。回归模型验证了两个方向各 630° 电机转角的正确累计及采样中断失效；本次真实 A→B 路径也是手动、连续追踪的多圈采集，未进行全行程通电驱动测试。

采集工具：`variants/m1-mt6835/tools/bench/leg_teach.py`。

```
# 新一轮采集先记录垂直 A 的当前单圈角度，再进入示教；已有记录不允许静默重置。
python variants/m1-mt6835/tools/bench/leg_teach.py --begin --record docs/data/leg-boundaries-20261014.json
# 手动转动期间保持控制板和磁编供电，可断开 USB；不得复位/重新烧录。
python variants/m1-mt6835/tools/bench/leg_teach.py --read --record docs/data/leg-boundaries-20261014.json
# 到 B 静止后记录；已有 B 不会被重复命令覆盖。
python variants/m1-mt6835/tools/bench/leg_teach.py --finish --record docs/data/leg-boundaries-20261014.json
```

诊断组 2 共 24 通道，JustFloat：0/1 为从 A 起算的有符号关节累计位移，4/5 为当前电机单圈磁编角度，7 为采样序列低 24 位，9/10 为桥输出模式（本模式必须均为 0），13/14 为 A 起点，15 为减速比，16 为协议版本，20 为故障，22 为示教状态（0 未启用、1 有效、2 失效），23 为组标记 2。组 1 原保留通道 22 也显示示教状态。

## 后续五连杆接入

机械记录保存于工程文件，当前未写入 MCU 机械参数区，也未用于自动启用全行程驱动。控制板保持示教禁能状态；无需持续串口连接即可维持当前多圈坐标。

电机侧单圈磁编无法在断电或 MCU 重启后独立恢复关节圈数：7∶1 下同一电机单圈读数每隔约 51.429° 关节角重复。以后应每次启动先在选定的可靠 B 边界建立圈数基准，或增设关节输出轴绝对编码器。仅存 A/B 单圈读数无法解决这个歧义。

五连杆位置控制还需主动杆/从动杆长度、两基座轴间距、M0/M1 的左右安装映射及装配分支。两台电机各自合法的角度组合仍可能导致机构碰撞或接近死点，应在运动学层校验可达性与奇异区，再与两端留量共同约束目标。
