# 近零位恢复关节位置（2026-10-16）

## 原失败原因

只读现场记录中，M0磁编约32.80°，保存基准11.2204°，差21.58°电机角、约3.08°关节角。旧 `leg home` 容差为±2°关节角，因此返回结果15（M0止点不匹配）。此前 `leg home confirmed` 仅采集本次上电零位，重启不会替换编译保存的基准。安装回差、贴合与支撑姿态变化会使严格止点校验反复失败。

## 改动

新增 `leg restore`，通过人工确认原上止点向内0°～40°区域，选择单圈磁编对应的唯一关节圈数。计算窗口−2°～40°，宽42°小于360°/7=51.4286°，−2°仅容纳基准附近回差；电机驱动仍要求0°～110°。当前姿态不会被置零，原保存参考、电角度和几何记录保留。

两路样本通过发布序号获得一致快照，候选计算在开中断状态完成，最后短暂成对提交。仅在双桥关闭、IDLE、无故障、采样运行且新鲜、两轴静止时允许；恢复本身不启动电机。重复命令保留已有效的连续跟踪。

VOFA按钮改为“① 恢复腿部位置”，增加区域确认和实际角度回显。协议功能位1024用于识别配套固件；结果19/20/21区分哪一路不在恢复窗口。恢复后角度在驱动范围外时，面板提示手动移入，阻止启动。

## 使用边界

恢复角度是相对原保存基准的估计，不自动纠正减速器回差或机械零偏。人工粗略区域是必要输入：10°与61.43°可能给出同一磁编读数，不能冷启动猜测整个110°行程。若要任意姿态冷启动，应增加输出轴绝对角度/多圈信息。

日常操作见[VOFA快速指南](wheel-leg-quickstart.md)。FOC10kHz、外环1kHz、前台轨迹200Hz、遥测50Hz及此前快速轨迹保护配置均保持。
