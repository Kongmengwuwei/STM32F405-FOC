# 双路轮腿接口

日常操作见[VOFA面板](wheel-leg-quickstart.md)；本页仅列硬件、命令与调度。构建使用 `Debug-dual-leg`。M0/M1都是L4225-6S420-A、TLE5012B、7∶1减速，当前验证电源12 V。

| 接口 | 功率/采样 | 磁编 |
|---|---|---|
| M0（正面右侧） | TIM1、PC0/PC1电流 | SPI1，PB3/PB4/PB5，CS PA1 |
| M1（正面左侧） | TIM8、PC3/PC2电流 | SPI3，PC10/PC11/PC12，CS PA0 |

关节正方向向行程内，M0磁编递增、M1递减。关节角为电机连续角除以7；原物理上止点为0°，驱动0°～110°，足端终点保留2°～108°裕量。保存基准见 `dual/leg_reference_config.h`，旧边界采集资料见[示教](leg-teach.md)。

| 命令 | 行为 |
|---|---|
| `leg restore` | 操作者确认原止点向内0°～40°、静止且输出关闭后恢复圈数；不改零位、不启动 |
| `leg pos q0 q1` | 关节目标（度），共用预检后的平滑轨迹 |
| `leg hold` | 从合法当前位置保持 |
| `foot pos x y` | 足端目标（mm），详见[运动学](fivebar-foot-control.md) |
| `leg rate 10` / `60` / `120` | 电机轨迹速度上限RPM；在关节模式/待机调整 |
| `foot speed 20` / `200` / `400` | 足端速度上限mm/s |
| `limit 10` | 关节模式电流指令上限A；在待机调整 |
| `stop` | 立即关闭双路，支撑重力负载 |
| `clear` | 原因排除后显式清故障，不自动启动 |
| `send 5` | 24通道面板状态，50 Hz，末通道5005 |
| `send 4` | 板端几何与标定，末通道4 |
| `send 2` | 原始角度/门极模式/故障诊断，末通道2 |
| `send 7` | 首次故障停机快照，末通道5007 |

运行期间主机应在500 ms内刷新有效目标；VOFA每50 ms自动刷新。不要将单电机 `send 6` 面板或其扫描命令用于当前双路固件。旧维护命令 `leg home` 会重新定义零位，日常使用恢复位置按钮。

FOC10 kHz、外环1 kHz、主循环轨迹200 Hz、模型和遥测50 Hz。先执行两路电流环/PWM写入，再执行错相外环；主循环解算和预检不长时间屏蔽ADC。保留门极关断、ADC/PWM时序、CRC、行程、500 ms失联、11 A硬过流和180 RPM超速保护。

电气记录与几何记录仍在Flash sector11；保存前关闭输出并暂停采集，兼容并保留单电机旧记录。不要整片擦除。清理版不改变记录布局、保存零位、几何参数和控制增益。
