# M0 ADC 验收记录

依据 `hardware-map.md` 中的板卡原理图，PA6/ADC6 接母线分压、PC0/ADC10 与 PC1/ADC11 接 M0 B/C 相电流放大器。最初的静态只读固件用软件触发轮询三路；下表保留这一步的历史验收值。当前固件改用 ADC2 软件触发读母线，ADC1 的两级注入序列由 TIM1 TRGO 上升沿以 10 kHz 触发，B/C 相使用 28 周期采样时间。

2026-09-23，经 VS Code STM32 扩展的 CubeProgrammer 使用 ST-Link 烧录并校验。探针报告目标电压 3.13 V；约 1200 次采样中 ADC 错误为 0，测得：

| 通道 | 近期原始值 | 启动后范围 | 说明 |
| --- | ---: | ---: | --- |
| 母线 PA6 | 810 | 804–816 | 以 3.13 V 为 ADC 参考、39 kΩ / 2.2 kΩ 标称分压估算，约 11.6 V；此值未经万用表校准 |
| M0 B 相 PC0 | 2022 | 2016–2030 | 驱动输入关闭时的零电流候选偏置 |
| M0 C 相 PC1 | 2029 | 2023–2037 | 驱动输入关闭时的零电流候选偏置 |

图纸标称 1 mΩ 分流电阻、20 倍放大；若仅按 3.13 V 参考估算，1 ADC 计数约 0.038 A。14 计数峰峰值约 0.54 A，但这是启动后极值范围，不能直接当作电流测量误差或 RMS 噪声。进入低电流转矩闭环前，须测实际零点与电流极性，使用与 PWM 固定相位同步的采样，并确认带电噪声、过流保护和电源限流条件。

上表对应早期只读固件，当时 PWM 尚未配置。当前固件复位后先保持输出关闭，再自动执行受限的启动检查；实物自动持续旋转尚未验收成功，故障会关断并锁存。

## 零电流偏置校准

新增 `App/Src/foc_current_zero.c`，在驱动输入保持关闭时收集 **256 组** B/C 相原始 ADC 值。任一路超出 1400–2700 计数、采样窗口内跨度超过 64 计数或 ADC 读取失败，校准即锁存失败；通过后才公布均值。阈值是启动阶段的粗略硬件合理性检查，尚不能当作闭环过流阈值。校准算法不依赖 HAL，后续可由 PWM 同步采样路径复用。

2026-09-23 初次静态实测：256 组采样后 `g_current_zero_status=FOC_CURRENT_ZERO_READY`，B 相零点 **2021.921875**、C 相零点 **2029.25390625** ADC 计数；窗口跨度分别 **5**、**4** 计数，ADC 错误 **0**。之后又在 TIM1 同步采样、输出关闭时重新取 256 组零点，实测跨度约 **10–13** 计数。该同步零点用于电流环。带电矢量试验显示正 alpha 电压下 B/C 相测得负电流，符合当前坐标约定；比例仍取 1 mΩ、20 倍放大的原理图标称值，未用外部电流表校准。详细运行数据见 `m0-torque-bring-up.md`。
