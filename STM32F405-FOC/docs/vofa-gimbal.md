# 双轴云台命令与 VOFA 界面

M0 为俯仰轴，M1 为水平轴。2026-10-03 新负载配置中，两轴上电中心附近的正常目标范围均为 −85°～+85°，实际行程超过 ±90° 停机。角度均为连续机械度，不做 0～360° 取模。

## 控制命令

使用原生 USB CDC（当前 COM8），ASCII 文本，每条以真正的 CR、LF 或 CRLF 结束。数字允许正负号和最多两位小数，如 `-12.50`；不接受 `nan`、科学计数法或多余参数。无需定时重复发送。

| 命令例子 | 动作 |
|---|---|
| `m0 pos 10` | M0 到 +10°，M1 目标不变；未启动时自动进入位置保持 |
| `m1 pos -10.50` | M1 到 −10.50°，M0 目标不变 |
| `gimbal pos 10 -10` | 同时设置 M0 +10°、M1 −10°，两轴都通过检查才提交 |
| `gimbal pos 0 0` | 两轴到软件零位并保持；不是停机 |
| `m0 hold` / `m1 hold` | 对应轴保持当前角度 |
| `m0 stop` / `m1 stop` | 关闭对应轴输出；取消尚未提交的双轴命令 |
| `stop` / `all stop` | 关闭两轴输出并取消待提交目标 |
| `m0 zero` / `m1 zero` | 仅停机时将该轴当前位置设为软件零位 |
| `clear` | 两轴停机并排除故障后清除锁定，不自动启动 |

双轴命令在两路本周期 PWM 写入完成后，于同一采样边界更新。解析时和提交时都会检查两个轴的校准、状态及目标范围；任一轴不满足则整条双轴命令被拒绝，保留原目标。`stop` 优先取消排队命令。原来的单轴命令继续可用。

**目标通道是固件是否接受命令的依据**：界面“已发送”仅表示串口发送函数已调用。USB 只返回二进制遥测，没有 ASCII 的 OK 回复。若目标没有改变，检查运行状态、故障码、校准及行程；不要通过反复发送或放宽限位绕过检查。

每次 MCU 复位都以第一笔有效编码器位置建立行程中心，因此烧录/复位前应将两轴和接线放回中间。`zero` 改变软件坐标，不改变行程中心或扩大允许行程。两轴输入框和滑条均限制为 ±85°；输入小数不代表机械精度达到该分辨率。两轴已有有效校准，安装关系未改变时不需重新 `cal`。

## VOFA 界面

- [控制控件](vofa/widgets/GimbalControl/GimbalControl.qml)：两个角度输入框、两条实时角度滑条、单轴/双轴发送、回软件零位、两轴停机，以及两轴各 12 个数值。打开布局、连接串口、编辑输入值都不会发送运动命令；点击发送按钮或手动拖动滑条才发送。
- [窗口布局](vofa-gimbal.tabview.json)：控制面板和目标/实际角度图。
- [全部窗口配置](vofa-gimbal.tabviews.json)与[全局配置](vofa-gimbal.config.json)：适用于本机 VOFA 1.3.10；重新安装或换显示缩放后可调整布局大小。
- [快捷命令](vofa-gimbal.cmds.json)：保持、回零、停机和清除故障；均为单次发送。
- [通道说明](vofa-gimbal.channels.json)与[本机 GBK 通道 CSV](vofa-gimbal.datas.csv)：24 通道顺序。CSV 的一行零值仅用于初始化名称，不能作为硬件正常的证据。

连接设置：**JustFloat、串口 COM8、1000000、8N1、无流控、DTR 开启**。当前双轴固件固定输出 24 个 float32 加 `00 00 80 7F` 帧尾，100 字节/帧、1 kHz；不需要 `send 6`。图的时间间隔为 **1 ms**，15,000 点约 15 秒。默认显示四条角度线，右侧可勾选电流、转速等通道。

本机控件安装目录为 `D:/APP/vofa+/x64/plugins/widgets/GimbalControl/`，持久化配置目录为 `C:/Users/kongmeng/AppData/Local/vofa+/100/context/`。外部配置修改前，原三个 JSON 和历史 CSV 已备份到 `build/gimbal-20261001/vofa-backup/`。其他电脑使用时：复制控件目录到 VOFA 的 `plugins/widgets/`，重启，再载入窗口布局及快捷命令；通道及串口设置参考上述表。旧的单轴 CSV 可能覆盖通道名，应使用当前双轴名称。

遥测未连接或中断时数值卡片显示“—”，角度发送按钮禁用。停机按钮在串口连接时可发送。**关闭 VOFA / 拔 USB 不会关闭电机；先点击停机并观察状态变为待机。** 俯仰轴停止驱动后可能因重力下落。两轴电流和速度保护保持此前调试参数，长期带载保持的温升尚未验收。

## 遥测顺序（从 I0 起）

| M0 | M1 | 内容 |
|---|---|---|
| I0 / I1 | I12 / I13 | 目标 / 实际转速，rpm |
| I2 / I3 | I14 / I15 | 目标 / 实际角度，° |
| I4 / I5 | I16 / I17 | 目标 / 实际 Iq，A |
| I6 | I18 | 实际 Id，A |
| I7 | I19 | 母线电压，V |
| I8 | I20 | 模式：0 电流、1 速度、2 位置 |
| I9 | I21 | 状态：0 待机、1 预充、2 校准、3 保存、4 运行、5 故障、6 校零、7 PWM 校零 |
| I10 | I22 | 故障码：0 无故障、1 编码器、11 超速、12 行程越界等 |
| I11 | I23 | 历史告警位，不等同于当前停机故障 |

控件发送接口采用 VOFA 的 `sys_manager.send_string`，通道绑定使用 `ChMenu.index`，见 [VOFA 官方控件接口](https://www.vofa.plus/docs/learning/widgets/development/)。
