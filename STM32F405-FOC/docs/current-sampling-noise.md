# 电流采样怎样降噪，同时保留快速响应

初次分析日期：2026-09-27。对象：当前 M0 + TLE5012B + ZH3620-1，10 kHz 电流环。以下分析依据源码和此前保存的原始记录。后续已完成采样点扫描，保留 8200；见[采样点实验](sampling-point-experiment-2026-09-27.md)。双 ADC 也已完成三轮对照，尚无稳定降噪收益，仍默认顺序采样；见[双 ADC 实验](dual-adc-experiment-2026-09-27.md)。采样长度和同周期平均仍待验证。

## 1. 先区分三个问题

1. **真实电流纹波**：绕组电流会随着 PWM 变化。即使电流平均值正确，不同时刻也可能测到不同值。
2. **测量噪声**：放大器、参考电压、地线、数字活动和 ADC 本身可能让不变的电流读数跳动。
3. **显示噪声**：抽取遥测可能把高频成分折叠成低频。VOFA 曲线是否平滑，不能单独证明电流环是否稳定。

当前 `send 5` 默认平均两次采样后以 5 kHz 发给 USB；电流反馈仍直接使用每次 10 kHz 的结果。采样分析必须保留完整 10 kHz 原始数据，不能只比较默认显示曲线。

## 2. 已有记录揭示什么

使用本地 `variants/m1-mt6835/build/bench_debug/20260927_current` 中 `repeat020_standby_raw.f32` 和 `ki024_standby_raw.f32`。这两组都是 PWM 输出关闭、完整 10 kHz 的原始 ADC 记录。

| 指标 | repeat020 | ki024 |
|---|---:|---:|
| B 相 ADC 标准差 | 1.35 码 | 1.40 码 |
| C 相 ADC 标准差 | 1.30 码 | 1.38 码 |
| B/C 相关系数 | 0.735 | 0.743 |
| 明显频谱分量 | 约 4 kHz | 约 4 kHz |

这些波动在关闭功率输出时仍存在，说明至少一部分噪声属于采样或电子电路。两路存在共同波动，但这些数据还不能定位到某一颗器件或某一条通信线路。

按当前 `3.13 V / 4095 × 50 A/V` 的换算，一个 ADC 码约为 **38.2 mA**。0.10 A 只相当于约 2.6 个码，0.20 A 约 5.2 个码；一两个码的波动已经相当显眼。这个电流比例还没有外部标定，文中的安培值是固件内部换算值。

程序用 B/C 重建 A 相，再做 Clarke 变换：`Ialpha = -Ib-Ic`，`Ibeta = (Ib-Ic)/√3`。共同噪声在前者相加，在后者相减。两组记录换算后的 alpha 噪声标准差约 94–99 mA，beta 约 21–22 mA。因此随着电角度变化，Id/Iq 的噪声也可能变化。

把样本按控制序号除以 5 的余数分组，可以看到周期性的 ADC 均值偏移。USART2 正好每五个控制周期发送一次遥测，2 kHz 活动的谐波可能与 4 kHz 分量有关。**这是待验证线索，不能认定 UART 就是根因。** 离线扣除五组偏移仅解释部分方差，大部分噪声仍然存在。不要把这种周期偏移补偿直接写进反馈，否则通信时序或数据改变后可能失效。

## 3. 当前采样实际发生在哪里

相关文件：`App/Config/foc_port.h`、`App/Hardware/bsp/bsp_adc_m0.c`、`App/Hardware/bsp/bsp_motor.c`、`App/FOC/foc.h`。

- TIM1 为中心对齐 PWM，168 MHz，ARR=8400；完整周期 100 µs。
- 计数从谷底到顶点需要 50 µs。
- CCR4=8200，在谷底之后约 48.81 µs 触发 ADC。
- ADC 时钟 21 MHz，每相采样 28 周期，12 位转换另需 12 周期。
- ADC1 顺序采 B 相、C 相，全部结束后进入电流处理。

以下时间忽略实际触发同步和中断延迟，是寄存器配置推算：

| 事件 | 相对于 PWM 谷底 |
|---|---:|
| ADC 触发，B 相开始采样 | 48.81 µs |
| PWM 计数顶点 | 50.00 µs |
| B 相采样保持结束 | 50.14 µs |
| C 相开始采样 | 50.71 µs |
| C 相采样保持结束 | 52.05 µs |
| 两相转换全部结束 | 52.62 µs |

两相保持时刻相差 **1.90 µs**。电流变化越快，这个错位越容易影响两相重建和坐标变换。

顶点附近的零矢量区间适合低侧电流采样，但真正应避开的是三相功率开关边沿及其后续建立过程。中心对齐计数器的顶点本身并不意味着三相都在此切换。低侧采样需要在对应低侧导通的有效窗口内进行，并给模拟前端留出建立时间。[TI 电流采样参考设计](https://www.ti.com/lit/tiducy7)

目前小电流测试的占空比接近 50%，功率边沿约在 25/75 µs，现有采样已远离边沿。仅移动半微秒，不能期待消除全部待机噪声。较大调制量时窗口会缩短，采样点和模拟建立时间就更加重要。

### 可以尝试哪个采样点

当前顺序采样窗口为 544 个定时器计数，另留 24 个计数的触发裕量。如果希望整个窗口在 PWM 顶点两侧具有相等裕量，几何候选为：

`CCR4 = (16800 - 544 - 24) / 2 = 8116`

相对于现在的 8200，提前 **0.50 µs**，两侧最小几何裕量增加 0.50 µs。8116 是便于比较的候选值，尚未证明噪声更低。

可比较 7800、8000、8116、8200、8300。每次只改一个参数，保持供电、通信、PI 和采样长度一致。修改时必须同步核查采样窗口、允许占空比和电角度预测；当前这些量通过 `FOC_HOLD_TICKS`、`FOC_EDGE_LIMIT` 等关联，不能只改触发寄存器。

## 4. 按低延迟优先安排改进

| 顺序 | 方案 | 对电流反馈延迟的影响 | 能解决什么、不能保证什么 |
|---|---|---|---|
| 1 | 对比待机 UART 遥测开/关，保留接收和相同 USB 记录 | 不增加 | 验证数字活动是否污染采样；频谱相关不能代替此对照 |
| 2 | 小范围扫描采样点 | 亚微秒到数微秒的时刻移动 | 找安静窗口；不能修复参考电压或增益问题 |
| 3 | 两相改为 ADC1/ADC2 同步注入采样 | 理论转换等待由约 3.81 降到 1.90 µs | 消除两相时间错位；不会自动消除共同噪声 |
| 4 | 采样长度由 28 改为 56 周期做对比 | 顺序两相多约 2.67 µs；同步两相多约 1.33 µs | 可改善 ADC 输入建立不足；不等价于多次平均 |
| 5 | 同一个 PWM 安静窗口内采两组并平均 | 增加数微秒，取决于触发实现 | 有机会降低随机噪声并保留周期响应；相关噪声收益小 |
| 6 | 必要时加轻量反馈滤波 | 见下文 | 降低剩余高频波动，同时改变闭环相位 |

ST 说明 ADC 采样时间应与输入源阻抗、采样电容建立过程匹配；延长采样时间应通过实际对照确认收益，不能当作必然降噪。[ST AN2834](https://www.st.com/resource/en/application_note/an2834-how-to-optimize-the-adc-accuracy-in-the-stm32-mcus-stmicroelectronics.pdf)

### 双 ADC 如何融入架构

M1 已使用双 ADC 同步方案，可参考它的采样驱动结构。M0 的 ADC2 现在负责母线电压；改造时需要让它承担 C 相注入采样，并把母线常规转换安排在电流采样完成之后。先核对实际芯片引脚的 ADC 通道支持，再落实主从触发、两路新鲜数据检查、错误标志清除和母线完成检查。

FOC 核心仍接收一对同一时刻的 B/C 电流。顺序或同步采样属于接口采样驱动的配置；采样长度、窗口和时刻应集中定义，避免它们在驱动、窗口预算和角度预测中各写一份。同步方案的转换完成更早，但最终电压仍在既定 PWM 更新点生效，不能直接把 1.90 µs 提前解释为整体环路延迟减少同样多。

### 同周期平均为什么更适合本项目

跨两个控制周期平均，在 10 kHz 下引入 50 µs 的线性相位延迟；在同一安静窗口内收集两组，样本只相隔几微秒。后者更适合尽量保留快速响应的目标。

但需要明确每组采样的触发和有效性，保证两相成对、模拟输入充分建立，且高占空比时仍容得下整个窗口。平均结果的电流时刻应使用样本中心，不能继续把末次采样当作唯一时刻。硬件切换噪声或低频共同扰动未必因两次平均而明显降低。

### 如果最终仍需反馈滤波

在 10 kHz 下，Ts=100 µs：

| 滤波 | 延迟说明 |
|---|---|
| 两点滑动平均 | 固定群延迟 50 µs |
| 三点滑动平均 | 固定群延迟 100 µs |
| 四点滑动平均 | 固定群延迟 150 µs |
| 一阶滤波 `y += α(x-y)`，α=0.8 | 低频等效延迟约 25 µs |
| 同上，α=0.7 | 低频等效延迟约 43 µs |
| 同上，α=0.5 | 低频等效延迟约 100 µs |

一阶滤波的延迟随频率变化，表中不是全频段固定延迟。任何反馈滤波加入后，都要重新验证 PI 阶跃、振荡和电压饱和；仅把 VOFA 曲线变平滑不算验证。

## 5. 实际验证顺序和判据

1. **待机基线**：完整 10 kHz ADC，比较均值、标准差、B/C 相关性、频谱。做 UART 遥测对照，先找到待机噪声来源。
2. **采样点对照**：同样条件扫描 CCR4，再对照 PWM 零矢量状态。记录零偏变化和最差采样窗口，不能只选择曲线最平的点。
3. **同步采样对照**：完成驱动改造后检查两路是否同周期、母线是否新鲜、ADC 错误和控制执行时间是否正常。
4. **采样长度或同周期平均**：分开试验，不与 PI 调整同时进行；噪声下降也不能以采样窗口不足为代价。
5. **短电流阶跃**：使用同样的 ±0.05/±0.10/±0.20 A 目标序列，比较原始误差、稳态均值、Id、响应时间、饱和比例和正负向差异。
6. **再整定 PI**：采样方式稳定后再调 Kp/Ki，最后评估速度环和位置环。

没有示波器也能做以上固件 A/B 对照，但它不能直接确认模拟前端的开关后建立时间。当前额外 3 µs 建立时间是暂定预算，应保留这一不确定性。若不同采样位置、同步方式和采样长度都没有明显收益，重点应转向 VDDA/VREF 去耦、模拟地回流、放大器输出驱动及 ADC 输入 RC，而不是不断增加数字滤波。

还要注意低电流分辨率：软件修改 A/V 系数不会增加真实 ADC 分辨率。提高硬件测量增益可能改善小电流观察，但会减少可测电流范围；需要按实际分流器、放大器和最大相电流重新计算。

**建议先做通信干扰对照和采样点扫描，再实现双 ADC 同步采样；必要时增加同周期平均，最后才加入跨周期反馈滤波。**

后续 UART 开/关对照已经完成，确认 UART 遥测路径贡献部分待机噪声；双 ADC 的现有引脚支持也已核对。见 [UART 验证与双 ADC 可行性](uart-noise-and-dual-adc-2026-09-27.md)。
