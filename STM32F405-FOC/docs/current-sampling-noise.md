# 电流采样与电流环：当前选择和实测依据

本页对应 **M0 + TLE5012B + ZH3620-1**。目前默认电流控制频率 10 kHz，ADC1 顺序读取 B/C 相，28 周期采样，TIM1 触发计数 8200。电流 PI 为 `Kp=0.20 V/A`、`Ki=192 V/(A·s)`、抗饱和回算 `1200/s`；反馈未增加跨周期低通。M1 使用独立的双 ADC DMA 路径，不能直接套用本页的 M0 时序数字。

## 为什么这样选

| 对照 | 观察 | 保留选择 |
|---|---|---|
| 采样点 7800、8000、8116、8200、8300 | 8116 与 8200 的原始 Iq 误差 RMS 均约 72.9 mA；1 ms 平均误差的差异小于 8200 自身批次波动 | 8200；未证明改点可以稳定降噪 |
| ADC1 顺序采样与 ADC1/ADC2 同步采样，交替各三批 | 原始误差 RMS 均值 72.29 与 72.73 mA；1 ms 平均误差 18.10 与 17.25 mA，同步采样首批反而较差 | 顺序采样；双 ADC 仍可在独立构建中实验，不需改硬件 |
| 28 与 56 周期采样 | 56 周期未降低误差，还占用更长的低侧有效窗口 | 28 周期 |
| 电流 Ki 24 与 192，塑料臂负载 | 小电流目标回零，批次平均曲线首次降至 0.02 A 由约 47.7 ms 缩到约 6.6 ms；转动中 Iq 跟随和速度反馈波动改善 | Ki=192；Kp 保持 0.20，Kp=0.30 未稳定获益 |

采样点与双 ADC 的 RMS 数字来自当时的 **Ki=24、小电流短阶跃、约 11.5–12 V** 实验，不是当前 Ki=192 固件的噪声指标，也不是外部电流探头读数。电流换算比例尚未独立标定。带臂最终小阶跃的稳态偏差为毫安量级，但高速、大占空比及持续工作仍需另测。当前选择也不能证明 8200 是所有负载与电角度的最佳采样点。

原始指标摘要分别在 [采样点数据](data/sampling-point-20260927.json)、[双 ADC 数据](data/dual-adc-20260927.json)、[电流 PI 数据](data/current-loop-loaded-20260927.json)。当前完整带臂、裸轴和最新定位表现见[负载对比](free-shaft-vs-plastic-arm-2026-09-28.md)与[定位提速](position-speedup-and-foc-roadmap-2026-09-28.md)。旧数据里的固件散列、参数、告警阈值只属于当次实验，不代表当前默认值。

## 控制和遥测如何区分

ADC 的每次新样本直接参与 10 kHz 电流 PI；`send 5` 的 USB 电流窗口平均只是显示与记录，**没有反向写入控制反馈**。默认 `send 6` 为 24 通道总览，M0 每 4 个控制周期发一帧。只把 VOFA 曲线滤平不能证明电机转矩更稳；应同时看目标跟随、实际轴运动和反馈延迟。比较不同方案时，保持电源、安装、命令与转子起始状态接近，按固件时间戳对齐目标变化，而非按 PC 串口写入时间。

## 后续调试顺序

1. 用外部仪器校准 B/C 两路电流增益、极性、零点与母线电压；确认三相电阻和电感的相/线定义。
2. 在当前顺序采样方案上，跨不同电角度、转速、调制量做重复阶跃和频率响应，记录电流目标、反馈、Ud/Uq、母线及饱和比例。
3. 仅当重复数据表明采样时刻或两相错位是主要误差时，再用独立构建目录试 `FOC_M0_TRIGGER_TICKS` 或 `FOC_M0_ADC_MODE=DUAL`。同步方案复用 ADC2 的 PC1 通道，不需更改板上电路；它改变采样窗口预算，必须复核硬件时序。
4. 最后考虑基于实测 R/L 的解耦或电压前馈，并检查饱和和正反向一致性；每次只改一项并与当前固件对照。

例如实验构建可用 `cmake --preset Debug-local -B build/Dual-adc-check -DFOC_M0_ADC_MODE=DUAL`。回到默认目录时明确配置 `-DFOC_M0_ADC_MODE=SEQUENTIAL -DFOC_M0_TRIGGER_TICKS=`，避免 CMake 缓存沿用实验选项。实机电流数值、栅极波形和模拟建立时间仍待仪器验证。
