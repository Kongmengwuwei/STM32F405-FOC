单电机 FOC · VOFA+ 24 通道总览分享包
整理日期：2026-10-01

一、这是什么
这是项目中保存的单电机总览：24 张数值卡片，加转速、位置、电流三张波形图。
转速图：目标转速、实际转速、斜坡转速（I0、I1、I18）。
位置图：目标位置、实际位置（I2、I3）。
电流图：目标 Iq、实际 Iq、目标 Id、实际 Id（I4～I7）。
FOCOverview 控件只显示数据，本身不会发送运动命令。

必须配合单电机固件的 send 6 数据格式：24 个 float32，加 JustFloat 帧尾，共 100 字节/帧。
该旧配置按 2.5 kHz 采样设置时间轴，delta_t = 0.4 ms；如果实际遥测频率不同，需要调整采样间隔。
双轴云台的通道定义不同，即使同为 24 通道，也不能直接套用本总览。

二、文件内容
original/vofa-overview.config.json    原始通信、通道和软件配置
original/vofa-overview.tabview.json   原始单个总览画布
original/vofa-overview.channels.json  通道对照说明，不是 VOFA 原生配置文件
context/vofa+.config.json            可直接恢复的配置，与原始配置相同
context/vofa+.tabviews.json          将原始画布封装成 VOFA 启动所用的画布集合
plugins/widgets/FOCOverview/         自定义数值卡片控件，需复制整个文件夹
SHA256.txt                          包内文件完整性校验清单

三、推荐安装方法（Windows）
1. 使用与原配置匹配的 VOFA+ 版本。配置版本标识为 vnumber = 100。
   若软件使用的是 140 配置目录，本包不能直接当作 140 配置覆盖。
   官方版本说明：https://www.vofa.plus/docs/function/release_note/
2. 启动一次 VOFA+，然后正常关闭。
3. 在资源管理器地址栏输入 %LOCALAPPDATA%\vofa+\100\context 并回车。
   先将该目录整体复制到其他位置备份，便于恢复原来的界面和设置。
4. 将本包 context 目录中的两个 JSON 复制到上述目录，替换同名文件。
   本包不含命令列表；对方现有的命令列表会保留。
   如果已有命令属于双轴云台，请勿将它们作为本单电机界面的操作说明。
5. 找到 VOFA+ 安装目录，在 plugins\widgets 下复制本包的 FOCOverview 文件夹。
   最终应为：<VOFA安装目录>\plugins\widgets\FOCOverview\FOCOverview.qml
6. 重启 VOFA+，应看到“FOC 总览（send 6）”标签页、24 张卡片和三张波形图。
   原布局面向 3840 像素宽画面；小屏幕上可能需要缩放界面、移动或缩小控件。

也可通过 VOFA+ 自带的载入功能使用 original 中的配置和单画布文件。
各版本入口可能不同；只有画布文件时，仍需载入配置以恢复通道名称与通信设置。
不要把 vofa-overview.channels.json 当作原生配置直接导入。

四、连接板子
1. 接运行对应单电机固件的板子，使用原生 USB 数据口，程序不能停在调试断点。
2. 协议选 JustFloat，连接方式选串口，选择对方电脑实际枚举出的 COM 口。
   原配置记录的是 COM8，需要按本机修改。
3. 通信设置：1000000、8 数据位、无校验、1 停止位、无流控；连接后确认 DTR 已打开。
   原生 USB CDC 的波特率设置不决定 USB 的物理速率。
4. 在发送框单次发送 send 6，并设置实际的 CR、LF 或 CRLF 行结束符。
   不要发送字面上的反斜杠和 n。send 6 仅切换遥测，不启动电机。
5. 24 张卡片和三张曲线应随接收数据更新。二进制接收文本显示乱码属正常。

五、通道对照
I0  目标转速 rpm              I1  实际转速 rpm
I2  目标位置 °                I3  实际位置 °
I4  目标 Iq A                 I5  实际 Iq A
I6  目标 Id A                 I7  实际 Id A
I8  母线电压 V                I9  Ud 电压 V
I10 Uq 电压 V                 I11 控制模式：0电流、1速度、2位置
I12 运行状态                  I13 故障编号
I14 告警位掩码                I15 最近告警
I16 命令拒绝次数              I17 电压可用比例
I18 斜坡转速 rpm              I19 速度环误差 rpm
I20 位置误差 °                I21 Iq 误差 A
I22 采样时间 us（低24位）      I23 采样序号（低24位）

六、常见问题
- 数值卡片不见了：检查 FOCOverview 文件夹路径，重启 VOFA+。
- 有数据但数值含义不对：检查是否为单电机 send 6；send 0～5 的旧组定义不同。
- 通道名被改掉：载入旧 CSV 表头可能覆盖名称，可重新载入本包配置。
- 串口打不开：先退出占用同一 COM 口的其他采集或串口程序。
- 波形时间比例不对：按固件实际遥测频率调整 delta_t（毫秒 = 1000 / 采样频率Hz）。
- 原来的界面被替换：关闭 VOFA+，恢复第3步备份，再重启。

操作运动命令时请使用对应单电机固件的说明。
旧 WARN 固件中断开 VOFA 或拔 USB 不会关闭 PWM；需要停机时发送 stop。
Iq 0、rpm 0、pos 0 的含义不同，不能统一当作停机命令。
