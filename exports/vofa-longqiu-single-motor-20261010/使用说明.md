# 龙邱 M1 单电机 VOFA 配置

适配当前分支的 L4225-6S420-A、M1、原 TLE5012B、12 V 固件，复用之前单电机的 24 张数值卡片及速度、位置、电流三张曲线。VOFA+ 1.3.10 使用 `vnumber=100` 的配置格式。

本机连接设置：**COM8 / JustFloat / 1000000 / 8N1 / 无流控 / DTR 开启**。总览为 `send 6`，每帧 24 个 float32 和 JustFloat 帧尾，共 100 字节；2.5 kHz 对应界面 Δt **0.4 ms**，25000 点缓冲覆盖 10 秒，默认显示最后 2 秒。换 USB 口后如端口变化，在连接页选择电机板实际端口。

打开 VOFA 后，点击左上角连接按钮。卡片应显示 12 V 左右母线电压、待机状态、零故障；三组曲线与卡片直接绑定当前固件通道。画布中间有单电机控制条，可输入速度、位置并发送；数字卡片本身不发送命令。左侧绿色命令列表保留常用命令供编辑和绑定原生控件，单击列表条目不会直接驱动电机。

建议操作顺序：

1. 点击画布中的“总览 send 6”，确保固件发送组与画面一致。
2. 停机后点击“当前位置设零”。
3. 输入目标后点击“发送速度”或“发送位置”。界面允许 ±300 rpm、±60°，初始输入为 10 rpm、5°，启动界面不会自动发送。位置是相对软件零点的绝对角度，不是增量。
4. 结束时点击“停机 · 关闭输出”，确认状态回到待机。

画布按钮均为单次发送，包含真实 CRLF 终止符，启动配置关闭发送框的循环发送。遥测中断超过约 1 秒时，运动按钮禁用，已连接串口的停机按钮仍可用。当前固件的 `WARN` 策略让目标持续有效；断开 VOFA 或拔 USB 不会停机。`rpm 0`、`pos 0` 和“保持当前位置”都会维持闭环，结束应使用 `stop`。已保存新电机校准，日常连接不需要重新校准；未放置直接电流驱动或重新校准快捷按钮。

配置生成包位于工程根目录 `exports/vofa-longqiu-single-motor-20261010/`。`context/` 内三份 JSON 分别包含连接/通道、画布和命令列表；`plugins/widgets/` 内包含 FOCOverview 数值卡片和 LongqiuControl 控制条，另有可单独导入的 `vofa-longqiu.tabview.json`。安装时会在该包 `backup/时间戳/` 中备份原设置、原控件和原数据 CSV。启动缓存 CSV 会用当前通道表头及一行零值占位替换（不代表实测），避免旧云台名称覆盖新通道；旧样本保留在备份里。

在本工程可重新生成配置；安装前先退出 VOFA，避免退出保存覆盖新配置：

```powershell
python STM32F405-FOC/docs/vofa/configure_longqiu.py --port COM8
# 本机路径默认 D:/APP/vofa+/x64 和用户 Local/vofa+/100/context
python STM32F405-FOC/docs/vofa/configure_longqiu.py --port COM8 --install
```

其他电脑可用 `--vofa-dir`、`--context-dir` 指定实际目录。恢复原设置时，退出 VOFA 后将备份中的 `context/` 三份 JSON 和原控件复制回对应目录，数据 CSV 复制回用户 `Local/vofa+/` 目录。

2026-10-10 动态响应参数已烧录并复测，速度图范围扩为 ±400 rpm、电流图 ±8 A，速度输入 ±300 rpm，并增加 ±150/300 rpm 命令。外环 Iq 上限 ±6 A 是控制余量，本次不是连续 6 A 验收。最新结果和剩余低速纹波见[动态响应记录](longqiu-dynamic-response-2026-10-10.md)。

2026-10-09 本机验收：COM8 实际收到 24 通道、400 μs 间隔的总览数据，待机母线约 12.21 V，故障和告警均为零。VOFA 重启后通道名正确，画布停机和 `send 6` 按钮均已核对真实串口发送回显，命令拒绝计数未增加。本次配置只验证待机通信，没有发送运动目标。
